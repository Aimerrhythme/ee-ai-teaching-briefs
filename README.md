# 电气工程 × 人工智能 · 每日作品仓

面向「电力系统 / 电气工程 + 机器学习」的**教辅向短作品**存档：结合当日公开资讯，围绕主题池写一篇可读短文（方法速览、仿真思路、文献/工具线索），供教学与课题讨论参考。

> **边界**：本仓库作品是主题启发下的公开知识整理与教学笔记，**不是**本科生毕业论文代写，也不替代学生本人的仿真、实验与论文写作。

## 怎么读

- [`themes.md`](./themes.md) — 待做 / 已做主题队列（Routine 按序取下一条）
- [`INDEX.md`](./INDEX.md) — 已发布作品目录
- `works/YYYY-MM-DD-slug/` — 单日作品（`README.md` 正文 + 可选 `refs.md`）

## 单篇结构（约定）

1. **今日切入**：主题一句话 + 为何今天写  
2. **背景 5 分钟**：电气问题 + AI 方法各一段  
3. **方法草图**：输入 / 模型或算法 / 输出与评价指标（概念级，可附伪代码）  
4. **最新公开信息**：1–3 条带链接的新闻、论文预印本、开源或标准动态  
5. **教辅提示**：可布置的小实验 / 常见坑 / 延伸阅读  
6. **免责声明**：教学参考，非工程投运依据

## 自动化

工作日定时：取 `themes.md` 中下一条 `todo` → 检索最新公开信息 → 写成一篇 → 提交本仓 → 在对话中告知链接。主题池空时只提醒补题。
