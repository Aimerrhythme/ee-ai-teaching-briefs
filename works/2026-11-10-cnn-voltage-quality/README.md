# 电压质量扰动时序 CNN 分类

日期：2026-11-10  
slug：`cnn-voltage-quality`  
关键词：电能质量，CNN，电压暂降，暂升，谐波，闪变

## 今日切入

主题池下一条是「把电能质量扰动波形当成时间序列，用一维 CNN 做多分类」：暂降、暂升、中断、谐波、振荡暂态、闪变各是一类，网络直接吃原始电压采样点，输出类别概率。今天值得写，是因为 2026 年这个方向出现了两个对课堂很有用的新动向：一是把同一套方法搬到 400 Hz 航空电网并真正部署到 FPGA 上，开始认真算「参数量—精度—时延」这笔账；二是不再满足于「准确率 99%」，转而要求分类器给出**带不确定度的解释**，告诉运维人员「它是看了波形哪一段才判成暂降的、有多大把握」。本篇按「扰动怎么定义 → 怎么用公式造数据 → CNN 草图 → 怎么诚实评价」做方法速览。

## 背景 5 分钟

**电气问题。** 电能质量扰动主要来自非线性负荷（变频器、电弧炉）、电容器组投切、电动机起动、变压器励磁涌流以及短路故障。IEEE Std 1159 对常见事件给出了按幅值和持续时间划分的定义，Basumallik 的论文（下文基线）按这一口径整理为：

- **暂降（sag）**：电压有效值下降 10%—90%，持续 0.5 周波—1 分钟；
- **暂升（swell）**：有效值上升 10%—90%，持续 0.5 周波—1 分钟；
- **中断（interruption）**：有效值下降 90%—100%；
- **谐波**：基波整数倍频率分量叠加；
- **振荡暂态**：投切等引起的衰减振荡；
- **闪变**：0.5—25 Hz 的低频幅值调制。

传统做法是「信号处理提特征 + 分类器」：先用短时傅里叶、小波、S 变换等提取特征，再接 SVM、决策树、模糊规则或浅层神经网络。痛点是特征要人设计，噪声一大、扰动一复合（例如暂降叠加谐波）就容易掉链子。

**AI 方法。** 一维 CNN 用一组可学习的卷积核在时间轴上滑动，相当于让网络自己学「滤波器组」：短核擅长抓尖峰和振荡，深层堆叠后感受野变长，能看到持续几个周波的有效值变化。最后用全连接层加 Softmax 输出各类概率，用交叉熵训练。和上一篇「五母线潮流 CNN」不同，这里的卷积沿**真实时间轴**滑动，「相邻采样点物理上相邻」是成立的，所以 CNN 在这里是很自然的选择，而不是教学上的权宜之计。

课堂主线建议：**先用公式造出六类波形把 CNN 跑通，再故意加噪、改窗长、加复合扰动，看准确率从哪里开始掉。**

## 方法草图

**输入（课堂尺度）**

- **造数据**：按扰动的参数化公式生成。以 Basumallik 论文的写法为例（\(u(t)\) 为单位阶跃，\(t_1,t_2\) 为起止时刻）：

\[
\text{暂降：}\ v(t)=V\left[1-\alpha\left(u(t-t_1)-u(t-t_2)\right)\right]\sin(\omega t),\quad 0.1\le\alpha\le0.9
\]

\[
\text{暂升：}\ v(t)=V\left[1+\alpha\left(u(t-t_1)-u(t-t_2)\right)\right]\sin(\omega t),\quad 0.1\le\alpha\le0.9
\]

\[
\text{振荡暂态：}\ v(t)=\sin(\omega t)+\alpha e^{-(t-t_1)/\tau}\sin(\omega_n t)
\qquad
\text{闪变：}\ v(t)=\left(1+\alpha\sin(\beta\omega t)\right)\sin(\omega t)
\]

  中断取 \(0.9\le\alpha\le1\) 的暂降式；谐波为基波加 3、5、7 次分量。每类随机抽取 \(\alpha,t_1,t_2,\tau\) 等参数，各生成几百条。
- **采样与窗长**：原论文按 5 kHz 采样。课堂上建议把**窗长**当成实验变量（例如 2、5、10 个周波），因为暂降最短只有半个周波，而闪变要几个周波才能看出调制。
- **噪声**：叠加高斯白噪声，信噪比从 50 dB 逐步降到 20 dB。
- **划分**：分层抽样（每类比例一致）切成训练 / 验证 / 测试，或做分层 k 折交叉验证；标准化统计量只在训练集上估计。

**模型或算法**

基线 A — **人工特征 + 浅层分类器**：每个窗口算有效值最小 / 最大值、总谐波畸变率（THD）、过零点间隔方差等，接决策树或随机森林。  
模型 — **1D CNN**：2—3 层 `Conv1d` + 激活（原文用 LeakyReLU）+ 池化 + 全连接 + Softmax，交叉熵损失，早停。  
扩展（只讲概念）— **多标签输出**：复合扰动（暂降 + 谐波）不再是单一类别，输出层改为每类一个 Sigmoid。

**输出与指标**

- **总体准确率** 与 **混淆矩阵**：重点看暂降 / 中断、闪变 / 正常这几对最容易混的类别。
- **各类召回率与宏平均 F1**：真实电网里扰动样本远少于正常样本，只看总体准确率会被多数类绑架。
- **噪声鲁棒曲线**：横轴信噪比，纵轴准确率。
- **推理时延与参数量**：若要放进监测终端，这两个数和精度同等重要（见下文文献 2）。

课堂用草图（概念级，不是某一仓库的训练脚本）：

```text
fs = 5000; f0 = 50; win_cycles = 10           # 窗长作为实验变量
t = arange(0, win_cycles/f0, 1/fs)

def gen(cls):
    a, t1, t2 = random_params(cls)            # 按各类公式的参数范围随机抽
    if cls == "sag":   v = (1 - a*(step(t-t1)-step(t-t2))) * sin(2*pi*f0*t)
    if cls == "swell": v = (1 + a*(step(t-t1)-step(t-t2))) * sin(2*pi*f0*t)
    ...                                       # 中断 / 谐波 / 暂态 / 闪变 / 正常
    return v

X, y = make_dataset(classes, n_per_class=500)
X_noisy = add_awgn(X, snr_db=choice([50, 40, 30, 20]))
split stratified; scale on train only

cnn = Conv1d(1,16,k=15) -> LeakyReLU -> MaxPool
   -> Conv1d(16,32,k=7) -> LeakyReLU -> GlobalAvgPool
   -> Dense(n_class) -> Softmax
fit(cnn, loss=CrossEntropy, early_stopping)

report accuracy, macro-F1, confusion matrix, acc vs SNR, params, latency
compare with: 有效值/THD 特征 + 随机森林
```

## 最新公开信息

1. **基线论文：Basumallik，「Voltage Quality Time Series Classification using Convolutional Neural Network」，arXiv:1904.00228。** 用 MATLAB 按上面的公式生成暂降、暂升、中断、谐波、暂态、闪变六类各 500 条，5 kHz 采样，分层 10 折交叉验证加早停，3 层 CNN 准确率约 99.83%，叠加 80 dB 高斯白噪声后约 99.67%。课堂上要提醒：**80 dB 信噪比的噪声非常小**，而且数据全部来自同一组公式，所以 99% 主要说明「CNN 能把公式参数空间分开」，不等于在现场录波上也能这么高；作者自己在展望里也写了要用 RTDS 实时仿真波形验证、补充复合扰动。这正好是一节「如何读懂高准确率」的好素材。  
   https://arxiv.org/abs/1904.00228

2. **航空 400 Hz 电网的扰动与故障检测：Guzmán、Babiceanu、Peköz，arXiv:2609.10479（2026-09 提交，已被 IEEE Transactions on Aerospace and Electronic Systems 接收）。** 参考波音 787 电气架构搭建高保真仿真，生成 21 类正常、扰动、投切、开路和短路工况，时间序列与短时傅里叶时频图两套数据各 73,500 条，时间序列数据集发布在 IEEE DataPort。统一条件下比较 1D / 2D CNN、LSTM、CNN-LSTM、ResNet、MobileNet、VGG，紧凑 ResNet 的精度—复杂度折中最好：软件测试准确率 96.94%，参数 175,685 个；8 位量化后部署到 Xilinx Zynq UltraScale+ ZCU102，准确率 95.87%，单条记录加速器平均时延 6.90 ms。课堂启示：基频从 50 Hz 换成 400 Hz，同样的窗长包含的周波数完全不同，窗长和采样率必须跟着基频重新设计；另外「量化掉了约 1 个百分点」是嵌入式部署时真实要付的代价。  
   https://arxiv.org/abs/2609.10479

3. **带不确定度的解释：Chen、Yu、Muttaqi，「A Bayesian Framework for Uncertainty-Aware Explanations in Power Quality Disturbance Classification」，arXiv:2604.13658（2026-04 提交）。** 指出常规可解释 AI 方法给出的是确定性的归因图，忽略了不确定性；作者为每个样本生成一个归因分布，让专家按置信度分位数挑选解释，并在合成与真实电能质量数据上做了实验。同组随后的 arXiv:2605.21114 把它推广成通用框架，在 15 类扰动基准上比较了三种贝叶斯神经网络近似。课堂启示：让学生把 CNN 的显著性图叠在暂降波形上，看网络是否真的盯着电压跌落的那几个周波；如果它盯着窗口开头的相位，说明数据生成有漏洞。  
   https://arxiv.org/abs/2604.13658

## 教辅提示

**小实验（由易到难）**

1. **画波形认类别。** 每类画 3 条波形并标出 \(t_1,t_2\)，让学生先肉眼分类，再对照 IEEE 1159 的幅值与持续时间口径判断是否「合规」，例如持续 0.3 周波的跌落算不算暂降。
2. **特征基线。** 只用有效值最小值、最大值和 THD 三个特征加随机森林，看能到多少准确率；通常暂降 / 暂升 / 中断很好分，闪变和暂态更难，这能说明 CNN 到底多学到了什么。
3. **噪声扫描。** 信噪比取 50 / 40 / 30 / 20 dB，画准确率曲线，并和原论文的 80 dB 设定对照讨论。
4. **窗长扫描。** 窗长取 2、5、10 个周波，观察闪变类的召回率怎么变，体会「感受野要覆盖调制周期」。
5. **进阶讨论。** （a）生成「暂降 + 谐波」复合扰动，单标签 Softmax 会怎么错，改成多标签 Sigmoid 后呢；（b）训练时故障起始相位总为 0°，测试时随机化，看准确率掉多少；（c）阅读文献 2，估算 50 Hz 与 400 Hz 下同样 20 ms 窗口各含几个周波。

**常见坑**

- 训练集和测试集来自同一套公式和参数范围，就宣称「可用于现场」。至少要在不同参数范围或真实录波上测一次。
- 噪声加得太轻（例如 80 dB）却把结果写成「抗噪能力强」。
- 只报总体准确率，不看混淆矩阵；暂降与中断的边界（剩余电压约 10%）本来就模糊。
- 窗口里扰动总是居中、起始相位固定，网络学到的是「位置」而不是「形状」。
- 标准化统计量用了全量数据，造成信息泄漏。
- 把不同论文的准确率横向比较谁更先进：类别数、数据来源、噪声设定都不同（文献 1 是 6 类公式数据，文献 2 是 21 类 400 Hz 仿真数据）。

**延伸阅读。** 先读文献 1 第 II 节（六类扰动的公式与参数范围），可以直接拿来造数据；再读文献 2 的摘要和数据集部分，看一个工程化的数据集需要多少类别、多少增强手段；对可解释性感兴趣的同学读文献 3 的摘要即可。可与继电保护或电能质量实验课联动：用实验台录到的真实暂降波形去测试仿真数据训练出来的模型。
