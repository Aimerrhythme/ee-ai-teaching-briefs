# 微网逆变器开关故障与异常 ML 检测

日期：2026-11-11  
slug：`microgrid-inverter-switch-ml`  
关键词：微网，逆变器，开路故障，开关定位，虚假数据注入（FDI），KNN

## 今日切入

主题池下一条把 11-03 那篇「光伏逆变器故障诊断」从**单台设备**扩展到**系统级**：在一个以逆变器为主的微网里（光伏 + 储能都经三相电压源逆变器并网），电流波形出现畸变时，要先回答「是逆变器里某个开关真坏了，还是传感器 / 通信链路上的测量被篡改了」，再回答「坏的是哪一个（或哪两个）开关」。今天值得写，是因为这条线在 2025—2026 年有明显推进：从「多点测量 + 普通分类器」走到「只用一个测量点 + 抗攻击训练」，并且开始把「测量是否可信」做成继电保护前面的一道独立校验层。本篇按「故障与异常怎么区分 → 分层分类草图 → 怎么诚实评价」做方法速览。

## 背景 5 分钟

**电气问题。** 三相两电平电压源逆变器有 6 个功率开关（IGBT），记作 S1—S6，每相桥臂上下各一个。常见内部故障有两类：

- **短路故障**：过电压或异常驱动信号导致，电流极大、极快，一般由硬件保护（去饱和检测、熔断器）在微秒级处理，不是数据驱动方法的主战场；
- **开路故障**：键合线脱落、门极驱动失效等导致某个开关「该开不开」。逆变器还能继续运行，但对应相电流出现半波缺失、直流偏置和谐波，长期运行会加重其他器件应力、恶化电能质量——**它不会立刻跳闸，所以需要诊断**。

在微网里还有第二种「看起来像故障」的情况：控制器依赖通信层传回的电压 / 电流测量，如果测量被**虚假数据注入（FDI）**篡改，控制器会按错误数据调节，电流同样会异常。两者的处置完全不同：开路故障要停机检修、换器件；FDI 要隔离通信链路、切换到可信测量。误判的代价是「派人去换一个没坏的 IGBT」或者「把真故障当攻击忽略」。

**AI 方法。** 课堂上可以把它拆成一个**分层分类**问题：

1. 检测：有没有异常（二分类）；
2. 定性：是硬件故障还是测量异常（二分类）；
3. 定位：哪一个 / 哪一对开关（多分类）。

输入通常先做 Clarke 变换（abc → αβ），把三相量压成两维，开路故障在 αβ 平面上表现为电流轨迹圆缺掉一块，形状直观，非常适合讲给专科学生。分类器从 KNN、决策树、SVM 到浅层神经网络都可以，**KNN 的好处是「按距离找最像的已知样本」，逻辑一句话讲得清**，适合作为第一个模型。

## 方法草图

**输入（课堂尺度）**

- **仿真对象**：一台三相两电平逆变器经 LC 滤波带阻性 / 阻感负载即可；要贴近原文，可以再接到一个小微网（多台逆变器 + 若干负荷）。基线论文用 MATLAB 搭了 9 母线、含光伏和储能的逆变器主导微网。
- **故障注入**：把某个开关的门极信号强制置 0 模拟开路。基线论文取 6 个单开关工况（S1—S6）和 6 个双开关组合（如 S1+S4、S1+S6、S3+S2 等），即 12 类故障。
- **异常注入（FDI 简化版）**：在电流传感器测量上叠加零均值高斯白噪声。基线论文在 0.3 s 采样窗口的 0.15 s 处注入，并把噪声幅值乘以系数 F，F 从 0 到 2、步长 0.05 扫描。作者的判别思路是：FDI 噪声在某一时刻**突然出现**，内部故障更多是渐变或尖峰，用均值、方差、自相关等统计特征可以区分。
- **特征**：αβ 电流 / 电压，或每个窗口的统计特征（各相电流均值——开路会带来直流偏置、方差、THD、自相关系数）。
- **划分**：按「工况（负载点、F 值）」分组切训练 / 测试，避免同一次仿真的相邻窗口同时出现在两侧。

**模型或算法**

基线 — **规则法**：各相电流归一化直流分量阈值判断（开路相电流均值明显偏离 0），只能定位到相，用来对照。  
模型 — **KNN**：特征标准化后用欧氏距离投票，k 取 3—7 做网格搜索。  
对照 — 决策树、SVM、浅层 MLP。  
结构 — 三个分类器串联（检测 → 定性 → 定位），或一个多类分类器直接输出「正常 / FDI / S1…S6 / 双开关组合」。

**输出与指标**

- **检测**：漏报率（真故障判正常）比误报率更要紧。
- **定性**：「故障 ↔ FDI」混淆矩阵，单独报两类误判各有多少。
- **定位**：多类准确率 + 宏平均 F1；看同一桥臂上下管（如 S1/S4）是否最容易互相混淆。
- **诊断时延**：从故障发生到给出结论用了几个基波周期。

课堂用草图（概念级，不是某一仓库的训练脚本）：

```text
cases = ["normal"] + ["S1".."S6"] + ["S1+S4","S1+S6","S3+S2","S3+S6","S5+S2","S5+S4"]
for case in cases:
  for load in load_levels:
    for F in [0, 0.05, ..., 2.0]:                # F=0 即无 FDI
      i_abc, v_abc = simulate_inverter(open_switches=case, load=load,
                                       fdi_noise=F*N(0,σ²), t_inject=0.15)
      i_ab = clarke(i_abc)                         # abc -> αβ
      for win in sliding(i_ab, len=1 cycle, step=1/4 cycle):
        X.append([mean, var, autocorr, thd per phase])
        y_status.append(case != "normal")
        y_type.append("FDI" if F>0 and t>0.15 else "HW" if case!="normal" else "none")
        y_loc.append(case)

split by (case, load, F) groups; scale on train only
m1 = KNN(k).fit(X, y_status)                       # 检测
m2 = KNN(k).fit(X[faulty], y_type[faulty])         # 硬件 vs FDI
m3 = KNN(k).fit(X[hw], y_loc[hw])                  # 开关定位
report recall(fault), confusion(HW vs FDI), macro-F1(loc), cycles-to-diagnosis
compare with: DC-offset rule, DecisionTree, SVM, MLP
```

## 最新公开信息

1. **基线论文：Kasimalla、Park、Hong、Kim、Lee，「AI-Enhanced Inverter Fault and Anomaly Detection System for Distributed Energy Resources in Microgrids」，arXiv:2411.08761。** 提出 FaultNet-ML 流程：采集三相电压电流 → 转 αβ/dq → 判断有无故障 → 判断是「异常」还是「硬件」→ 定位单开关 / 多开关；在 MATLAB 搭建的 9 母线逆变器主导微网（含储能与光伏）上验证，比较了 DT、KNN、SVM、NN、ANN。论文给出的四种场景中，KNN 准确率分别约为 89.40%（单开关无异常）、93.60%（单开关有异常）、98.81%（多开关无异常）、97.16%（多开关有异常），ANN 在四种场景都在 99.6% 以上，后两种报到 99.99%。课堂上要提醒：数据全部来自同一套仿真，FDI 被简化成「定时注入白噪声」，而且论文里 NN 与 ANN 的结构差异没有说清；99.99% 更适合当作「问题在该设定下可分」的证据，而不是现场性能。  
   https://arxiv.org/abs/2411.08761

2. **单测量点 + 抗攻击训练：Wang、Yu、Xia、Xu，「Cyber-Resilient Fault Diagnosis Methodology in Inverter-Based Resource-Dominated Microgrids with Single-Point Measurement」，arXiv:2511.13162（2025-11 提交）。** 只用一个 VPQ（电压、有功、无功）测量点，先用 Caputo 与 Grünwald-Letnikov 两种分数阶导数构造特征库放大微小扰动和慢漂移，再用两级分层分类器先定位到逆变器、再隔离到具体 IGBT，并用渐进式记忆回放对抗训练提高抗攻击能力。在四逆变器测试平台、1 类正常 + 24 类故障上，无攻击时诊断准确率 96.7%，偏置、噪声、数据替换、重放四种攻击下分别为 96.6%、94.0%、92.8%、95.7%。课堂启示：（a）「先定位到哪台逆变器、再定位到哪个开关」正是上面草图里的分层思路；（b）FDI 不止加噪声一种，偏置、替换、重放各有各的难点，可以让学生逐一实现。  
   https://arxiv.org/abs/2511.13162

3. **把「测量可信吗」做成保护前的校验层：Saber 等，「An AI-Based Supervisory Measurement Integrity Validation Layer for Cyber-Resilient AC/DC Protection in Inverter-Based Microgrids」，arXiv:2604.23666（2026-04 提交）。** 面向线路电流差动保护：在逆变器主导微网里故障电流幅值受限，「电流大不大」不再可靠，作者用循环神经网络读取继电器本身可得的短窗同步电流，判断其物理一致性，区分真故障和被篡改的测量流，不需要额外传感器或拓扑信息；在孤岛逆变器微网上评估，并用 OPAL-RT 实时仿真做了硬件在环验证。被误判的样本主要是「只轻微扰动的隐蔽 FDI」和「靠近继电器的高阻故障」，两者轨迹本来就相似。课堂启示：这正好解释了为什么「故障 vs 攻击」的边界样本最难，适合作为讨论题。  
   https://arxiv.org/abs/2604.23666

## 教辅提示

**小实验（由易到难）**

1. **看 αβ 轨迹。** 正常运行时 αβ 电流轨迹接近圆；分别让 S1、S4 开路（按常见编号二者同属 a 相桥臂，以自己电路的编号为准），画出轨迹，让学生描述「缺了哪半边」，并解释为什么同一桥臂上下管开路时缺口方向相反。
2. **规则基线。** 只算三相电流一个周期内的均值（直流偏置），设阈值判断哪一相出问题，统计能定位到相、但定位不到上管 / 下管的比例。
3. **KNN 跑通。** 用统计特征做 13 类（正常 + 12 类故障）分类，扫描 k = 1、3、5、7，画混淆矩阵，找出最容易混的开关对。
4. **加入 FDI。** 按 F = 0—2 扫描噪声强度，分别统计「FDI 判成硬件故障」「硬件故障判成 FDI」两种错误率随 F 的变化；F 很小时 FDI 几乎看不出来，讨论这种情况下误判是否可以接受。
5. **进阶讨论。** （a）把 FDI 从加噪声改成加固定偏置或重放一段历史数据（参照文献 2 的四种攻击），原来的统计特征还管用吗；（b）测试集换一个训练时没见过的负载点，准确率掉多少；（c）阅读文献 3 的摘要，讨论「故障电流受限」对传统过流保护意味着什么。

**常见坑**

- 同一次仿真切出的相邻窗口分到训练和测试两边，准确率虚高；要按工况分组划分。
- 只报总体准确率：正常样本通常最多，会掩盖少数故障类的漏报。
- 窗口里没有包含故障发生时刻，或者窗口太短（不足一个基波周期），开路特征来不及显现。
- FDI 只模拟了一种形式（白噪声），就宣称「能区分攻击与故障」。
- 把不同论文的准确率横向比较：文献 1 是 9 母线仿真、12 类故障 + 白噪声 FDI，文献 2 是 25 类、四种攻击，设定完全不同。
- 忽略控制环的影响：闭环电流控制会部分「补偿」开路畸变，开环和闭环仿真得到的数据分布不一样。
