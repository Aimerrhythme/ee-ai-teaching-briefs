# 日前电价预测 LEAR 与 DNN 对比（2026-11-26）

> 主题：`epf-day-ahead-lear-dnn` · 关键词：电价预测、电力市场、LEAR、DNN  
> 定位：教辅 / 技术速览，供课堂与课题讨论参考；不是毕业论文代写。

## 1. 今日切入

**一句话**：日前市场每天中午前一次性出清「明天 24 个小时」的电价，所以日前电价预测本质上是**一次给出 24 个数**的多输出回归；在这个问题上，一个「247 个候选特征 + LASSO 自动挑选」的线性模型（**LEAR**）至今仍是深度网络（**DNN**）必须正面打败的强基线——任何新方法都应该先和它、再和朴素基线比一比。

**为何今天写**：本仓已经有负荷预测（`cnn-bilstm-residential-load` 11-04、`lstm-ev-charge-forecast` 11-19）和分时电价下的储能调度（`drl-bess-dispatch` 11-18），但还缺中间那一环——**价格本身怎么预测**。储能套利、需求响应、售电公司报价都要先有一条明天的价格曲线。今天用 Lago 等人的开源基准（epftoolbox）把「朴素基线 → LEAR → DNN」这条对比路线讲清楚，同时顺带讲电力现货市场的「日前出清」概念。

## 2. 背景 5 分钟

**电气问题**：在集中竞价的日前市场里，发电侧提交报价曲线、用电侧提交需求曲线，交易机构在 D-1 日对 D 日每个时段统一出清，得到每小时一个**统一出清价**。价格大致由「剩余负荷（负荷 − 风光出力）」落在**报价阶梯（merit order）** 哪一段决定：
- 剩余负荷低（夜间、大风天）→ 落在低价机组段，甚至出现**负电价**（新能源保障消纳、灵活性不足时）；
- 剩余负荷高（晚高峰、无风）→ 落到昂贵调峰机组段，价格陡升形成**尖峰**；
- 燃料价、碳价的慢变化会整体抬升或压低这条阶梯——这让价格序列**非平稳**。

因此日前电价有强烈的日内形状、周内效应（周末低）、尖峰与负价，且严重依赖**外生量**：日前负荷预测与风光出力预测。专科讲清「剩余负荷 → 阶梯 → 价格」这一条即可；专升本/本科可延伸到节点电价、阻塞与储能套利。

**AI 方法**：
- **LEAR**（LASSO Estimated AutoRegressive）：对每个小时 h 单独建一个线性 ARX 模型，候选输入很多（前几天的全部 24 点价格、外生量、星期哑变量），用 **L1 正则（LASSO）**同时估计参数和自动剔除无用特征；价格先做 **asinh 方差稳定化**变换来压住尖峰。优点是快、能每天重新标定、系数可解释。
- **DNN**：一个普通的前馈多层感知机，**单模型一次输出 24 个价格**（多变量框架），输入特征和超参数用贝叶斯优化（TPE）自动挑选。能刻画非线性（例如尖峰段的陡升），但需要更多数据和调参。
- Lago 等（2021，见第 4 节）的结论是：在 5 个市场各 2 年测试期上，**DNN 在线性误差指标上普遍优于 LEAR，DNN 集成最好**；但 LEAR 依然很强、计算代价低得多。

## 3. 方法草图

**输入**（预测 D 日 24 个价格 $p_{d,1..24}$，Lago 等的设定，共 247 维）
- 历史价格：$p_{d-1}, p_{d-2}, p_{d-3}, p_{d-7}$ 各 24 点（96 维）；
- 两个外生量（如日前负荷预测、风电预测）：D 日的 24 点，以及 D-1、D-7 日的 24 点（2×3×24 = 144 维）；
- 星期哑变量 7 维。

**模型（概念级）**
```
LEAR（每小时一个）：
  价格 → asinh 变换
  for h in 1..24:  min_θ  Σ_d (p̃_{d,h} − θ_h·X_d)²  +  λ_h ‖θ_h‖₁     # 247 个候选，多数系数被压成 0
  预测 → asinh 逆变换；每天（或每周）滚动重标定，可用短窗（56 天）+ 长窗（数年）做集成
DNN（一个模型）：
  X_d (247) → Dense+ReLU → Dense+ReLU → Dense(24)    # 一次输出 24 小时
  Adam 训练 + 早停；超参/特征用 TPE 搜索；多种子/多配置集成
```

**评价指标**
- **MAE**（主指标，市场结算本身是线性的）、**rMAE** = 模型 MAE / 朴素基线 MAE（Lago 等推荐用「一周前同小时」$p_{d-7,h}$ 作分母，跨市场、跨时段可比）、sMAPE、RMSE；
- **不推荐 MAPE**：价格接近 0 或为负时 MAPE 会爆掉（Lago 等的表里德国市场 MAPE 高达约 80%–130%，而 sMAPE 只在约 14%–17%）；
- 比较两个模型时用 **Diebold-Mariano / Giacomini-White 检验**看差异是否显著，而不是只比一个数；
- 测试期至少覆盖**一整年**（最好两年），否则节假日、季节效应无法体现。

**输出**：D 日 24 点价格曲线 → 储能充放计划、报价策略、需求响应时段选择等下游决策。

**本目录附带的合成数据演示**：[`epf_lear_dnn_demo.py`](./epf_lear_dnn_demo.py)（仅依赖 numpy；本机约 6 分钟，主要耗在纯 Python 的 LASSO 坐标下降）  
合成 3 年（3×364 天）逐时数据：日前负荷预测（双峰日曲线、冬高夏低、周末 ×0.85）、日前风电预测（日均值 AR(1) 天气过程）、燃料价缓慢漂移；电价 = 燃料价 ×（线性阶梯）+ 高剩余负荷的指数型尖峰 − 低剩余负荷时的负价项 + 日间持续的随机残差。特征完全照搬上面的 247 维设定。前 2 年标定，**最后 364 天**测试，每 28 天滚动重标定一次。对比：
① 两种朴素基线；② LEAR，标定窗 56 天 / 728 天及二者平均；③ DNN（247→64→32→24，MAE 损失、Adam、早停，**未做超参搜索**）单种子与 4 种子集成。

本机（2026-11-26）运行输出（完整输出见 [`demo_output.txt`](./demo_output.txt)）——测试集价格均值 39.83 €/MWh，最小 −9.98，最大 75.26，负电价小时占 0.84%，尖峰阈值（95 分位）54.47：

| 方法 | MAE | rMAE | sMAPE[%] | RMSE | 尖峰小时 MAE |
|---|---|---|---|---|---|
| 朴素：一周前同小时 p(d-7,h) | 6.16 | 1.000 | 18.45 | 8.45 | 7.52 |
| 朴素：标准日翻日（周一/六/日用 d-7） | 5.04 | 0.817 | 15.86 | 7.13 | 5.25 |
| LEAR-56 | 3.45 | 0.559 | 10.58 | 5.21 | 4.91 |
| LEAR-728 | **2.83** | **0.459** | **8.80** | **3.95** | 6.09 |
| LEAR 集成(56+728) | 2.91 | 0.471 | 9.23 | 4.07 | **4.58** |
| DNN (seed 0) | 3.59 | 0.583 | 10.62 | 5.21 | 8.59 |
| DNN 集成(4) | 3.25 | 0.527 | 9.63 | 4.95 | 8.93 |

LEAR 每小时模型平均非零系数（247 个候选中）：56 天窗 19.5 个，728 天窗 62.0 个。

读法：
1. **朴素基线不是摆设**：仅仅"用昨天的价格（周一和周末用上周同日）"就把 rMAE 降到 0.817；新模型至少要先赢过它。rMAE 这一列让不同方法一眼可比。
2. **LEAR 很强**：长窗 LEAR 的 MAE 2.83，约为一周前朴素基线的 46%。LASSO 在 247 个候选里平均只保留 20–60 个，**数据越少保留越少**（56 天窗只有 56 个样本，模型被迫更稀疏）——这是 L1 正则"自动做特征选择"的直观体现。
3. **标定窗口是一对矛盾**：长窗样本多、整体误差最低；短窗只看最近 8 周，更能跟上燃料价漂移带来的水平变化，在**尖峰小时**反而更准（4.91 vs 6.09）。两者平均的集成拿到了最低的尖峰误差（4.58），整体 MAE 也接近最优——这正是 Lago 等推荐"短窗 + 长窗"集成的原因。
4. **这个玩具里 DNN 输给了 LEAR**，与论文结论相反，原因值得课堂讨论：合成电价主体本身就是"燃料价 × 线性阶梯"，线性模型几乎是对的结构；标定集只有约 580 个训练日，要拟合 247→64→32→24 的约 1.8 万个参数；且没做任何超参/特征搜索。论文里的 DNN 有每个市场 4 年数据、TPE 优化输入与超参，才系统性地胜出。**"深度模型更好"是有条件的**。
5. **集成对 DNN 尤其有用**：4 个随机种子平均后 MAE 从 3.59 降到 3.25，说明单个网络的随机初始化方差不小。
6. DNN 在尖峰小时误差最大（约 8.6–8.9）：尖峰样本少、早停又偏向"平均情况"，这是数据驱动模型在极端价格上的通病。

合成数据远比真实市场简单，数字只用于课堂讲清概念，不代表任何真实市场或 epftoolbox 中模型的性能。

## 4. 最新公开信息

1. **Forecasting day-ahead electricity prices: A review of state-of-the-art algorithms, best practices and an open-access benchmark**（Jesus Lago, Grzegorz Marcjasz, Bart De Schutter, Rafał Weron；arXiv:2008.08004，2020-08；期刊版 *Applied Energy* 293 (2021) 116983，DOI 10.1016/j.apenergy.2021.116983）

## 5. 教辅提示

**可布置的小实验（2–4 学时）**
1. 运行 `epf_lear_dnn_demo.py`，先只看两行朴素基线，让学生解释"为什么周一要用上周一而不是周日"；再看 LEAR / DNN 结果，讨论 rMAE 的含义。
2. 打印某个小时（如 h=19 晚高峰）LEAR-728 的非零系数，看它选中了哪些特征、是否以 $p_{d-1}$ 和当日负荷/风电的邻近时段为主，把"LASSO 做特征选择"变成看得见的结果。
3. 把燃料价的漂移噪声（`rng.normal(0, 0.6)`）调大到 1.2，观察短窗 LEAR-56 与长窗 LEAR-728 的优劣是否翻转——理解非平稳性与标定窗口的关系。
4. 把重标定间隔 `REC` 从 28 改为 7，看误差能降多少、耗时增加多少，体会"逐日重标定"的工程代价。
5. 本科 / 专升本延伸：`pip install` 安装 epftoolbox，跑 `examples/recalibrating_lear_simplified.py` 在一个真实市场（如 Nord Pool）上复现 LEAR，用库里的现成 DNN 预测算 rMAE 并做 DM 检验；再把预测曲线接到本仓 `drl-bess-dispatch` 的储能套利环境里，比较"用预测价"与"用真实价"调度的收益差。

**常见坑**
- **用 MAPE 评电价**：价格接近 0 或为负时 MAPE 失效，用 MAE / rMAE / sMAPE。
- **信息泄漏**：D 日的外生量必须用**日前预测值**（D-1 日可得），不能用 D 日的实际负荷/实际风电；价格滞后最近只能到 $p_{d-1}$。
- **测试期太短**：只测一两周，节假日和季节效应全被忽略，结论不可靠。
- **只和弱基线比**：只赢过 ARIMA 或单层 MLP 不能说明方法先进；至少要和 LEAR、朴素基线比，并做显著性检验。
- **不重标定**：价格机制会变（燃料价、新能源装机），模型训练一次就一直用，误差会逐渐变大。
- **直接套用国外市场结论**：国内省级现货市场的出清规则、限价、时段划分（如 15 分钟 / 96 点）与欧洲日前市场不同，迁移时要先核对规则。
