# PMU 同步相量 Isolation Forest 异常检测（2026-11-16）

> 主题：`iforest-pmu-anomaly` · 关键词：PMU、异常检测、Isolation Forest、广域监测  
> 定位：教辅 / 技术速览，供课堂与课题讨论参考；不是毕业论文代写。

## 1. 今日切入

**一句话**：PMU 每秒几十帧地上传电压/电流相量和频率，里面混着真实扰动、通信丢包和坏数据；用 Isolation Forest（孤立森林）这种**无监督**算法先把"不正常的帧"挑出来，是广域监测数据质量课的一个好入门点。

**为何今天写**：近期公开文献里出现两条值得放进同一节课对照的线索——一篇 PMU 无监督异常检测预印本（2026-04 更新 v2）把 Isolation Forest 当作基线，与自编码器、GAN 等深度模型同台比较；另一篇 2026 年 8 月的输电故障预印本把 Isolation Forest 放在"两阶段流水线"的第一级做检出。正好能讲清"简单基线的价值和边界"。

## 2. 背景 5 分钟

**电气问题**：PMU（相量测量单元）用 GPS 对时，输出带时标的电压/电流幅值、相角、频率及频率变化率（ROCOF），汇聚到 PDC（相量数据集中器）后供广域监测、振荡分析、状态估计使用。现场数据常见问题：
- **坏数据**：通道跳变、毛刺、常值卡死、对时异常导致的相角跳变；
- **通信问题**：丢包、重复帧、延迟；
- **真实电网事件**：短路、切机、负荷突变引起的频率/电压偏移。

前两类要过滤，第三类要告警。难点是标签稀缺——没人会逐帧给你标"这帧是坏的"。

**AI 方法**：Isolation Forest 的直觉是"异常点又少又怪，所以容易被孤立"。它反复随机选一个特征、在取值范围内随机切一刀，构成很多棵随机二叉树；某个样本被孤立所需的平均路径越短，异常分越高。优点：不需要标签、训练快、对高维特征友好、几乎没有分布假设。缺点：**逐帧看数据时没有时间上下文**，对缓慢漂移、细微频率偏差不敏感，阈值（contamination）需要人定。

## 3. 方法草图

**输入**
- 每帧特征：各 PMU 的电压幅值 |V|、相角差（相对参考母线）、频率 f、ROCOF；
- 建议补"时间上下文"特征：一阶差分 Δ|V|、Δf，滑动窗（如 10–30 帧）的均值/标准差；
- 先做标准化；相角要先**相对参考母线做差并解卷绕**，否则 ±180° 跳变会被误判。

**模型**
```python
# 概念级伪代码（scikit-learn）
from sklearn.ensemble import IsolationForest
X_train = features(normal_period)          # 尽量用"大致正常"的时段训练
clf = IsolationForest(n_estimators=200, contamination=0.01, random_state=0)
clf.fit(X_train)
score = -clf.score_samples(features(stream))  # 越大越异常
alarm = score > threshold                      # 阈值用验证集选，例如 Youden J
alarm = debounce(alarm, k=3)                    # 连续 k 帧才报警，抑制抖动
```

**输出与评价**
- 帧级：Precision / Recall / F1 / ROC-AUC（异常很少，**不要只看准确率**）；
- 事件级：检出延迟（从注入到首次报警的帧数）、每小时误报次数；
- 解释：对报警帧看是哪个 PMU、哪个通道偏离最大，做"先检出再解释"。

**对照方法（课堂可选）**
- 统计基线：滑动 3σ / 中位数绝对偏差（MAD）；
- 重构类：PCA 重构误差、（LSTM）自编码器重构误差。

## 4. 最新公开信息

1. **T-BiGAN：PMU 时空异常无监督检测**（arXiv:2509.25612，v1 2025-09-30，v2 2026-04-11）  
   用窗口注意力 Transformer + 双向 GAN 做 PMU 流异常检测，在硬件在环 PMU 基准数据上报告 ROC-AUC 0.95。对课堂最有用的是它的基线表：Isolation Forest 为 Precision 0.61 / Recall 0.75 / F1 0.67 / ROC-AUC 0.82，PCA 为 F1 0.64，LSTM-AE 为 F1 0.72（均为该文 5 个随机种子的均值）。可以让学生讨论：深度模型多出来的精度来自"时空上下文"，代价是 GPU、调参和可解释性。  
   https://arxiv.org/abs/2509.25612
2. **输电故障检测与分类的两阶段混合 ML 流水线**（arXiv:2608.23726，2026-08）  
   第一级用 Isolation Forest 做异常检出（对孤立森林分不开的故障类别，训练时自动补一个有监督二分类器，按 OR 规则融合），第二级只对被检出的样本用随机森林做故障分类；特征里加入了由对称分量法得到的零序分量。文中报告在单测点数据集上端到端准确率 97.25%、CPU 单样本约 0.05 ms。说明"无监督先检出 + 有监督再分类"的工程思路。  
   https://arxiv.org/abs/2608.23726
3. **经典参考：Isolation Forest + KMeans + LoOP 的实时同步相量异常检测与分类**（IEEE Trans. Smart Grid，2021，DOI 10.1109/TSG.2020.3046602）  
   较早系统地把孤立森林用在同步相量数据上，并与聚类、局部离群概率组合做分类，适合作为延伸阅读的"起点文献"。

## 5. 教辅提示

**可布置的小实验（2 学时）**
1. 生成或选用一段"正常"PMU 序列（可用简单动态仿真或公开示例数据；无数据时用正弦 + 噪声合成 50 Hz 频率与幅值序列）。
2. 注入四类异常：单点毛刺、连续丢包（填 NaN 或保持上一值）、0.05–0.2 Hz 级频率阶跃偏移、缓慢漂移。
3. 分别跑：滑动 3σ、Isolation Forest（仅原始特征）、Isolation Forest（加差分与窗口统计特征）、PCA 重构误差。
4. 填一张表：四类异常 × 四种方法的 Recall 与误报次数；画异常分时序图。

**预期讨论点**：毛刺和阶跃对孤立森林很容易；缓慢漂移在只用原始特征时几乎检不出来，加了窗口特征才有改善——这正对应文献 1 里说的"缺少时间上下文"。

**常见坑**
- 相角不做参考差和解卷绕，误报一大片；
- contamination 随手设 0.1，等于先认定 10% 数据是坏的；
- 把注入异常的时段也放进训练集，模型把异常"学成正常"；
- 丢包用 0 填充，模型检出的是"填充值"而不是问题本身；
- 只报帧级准确率，异常占比 1% 时全判正常也有 99%。

**延伸阅读**：IEEE C37.118.1/2（同步相量测量与数据传输标准）、PMU 数据质量相关综述；与已有作品 [配网短路故障分类与定位](../2026-11-12-ml-fault-class-loc/README.md)、[电压质量扰动 CNN 分类](../2026-11-10-cnn-voltage-quality/README.md) 可串成"检出 → 分类 → 定位"的系列课。
