# 基于 PID 优化与神经网络的电机调速控制系统

日期：2026-10-24  
slug：`pid-nn-motor-speed`  
关键词：PID，神经网络，电机调速

## 今日切入

主题队列的第一条是转速环上的 PID，加上神经网络做增益自适应。固定增益 PID 仍是直流伺服和永磁同步电机（PMSM）调速的默认外环；负载、惯量或电阻一变，同一组 $K_p,K_i,K_d$ 就会在超调和恢复时间之间顾此失彼。2024–2025 年仍有公开论文把 BP / RBF 或学习型优化接在这条外环上，直流电机与 PMSM 都有实例，适合作为本系列的第一篇方法速览。

## 背景 5 分钟

**电气问题。** 直流电机里，电枢电压决定电流，电流决定电磁转矩，转矩与负载、摩擦一起决定转速。PMSM 常用磁场定向控制：内环调节 $i_d,i_q$，外环用转速误差给出 $i_q$ 参考。两种对象的外环都可以写成「转速误差 → 控制量」。教科书上的一组 PID 是在标称惯量、标称负载附近整定的。惯量增大、负载阶跃或绕组温升后，同一组增益要么变慢，要么超调、振荡。输出碰到电流或电压限幅时，积分还会持续累积，转速回到给定以后仍要花一段时间把积分退掉。

**AI 方法。** 课堂上最常见的接法，不是用神经网络替换逆变器，而是让网络在每个采样周期读取误差特征，输出或修正 $K_p,K_i,K_d$，执行器仍是增量式 PID。网络可以在线反传（BP、RBF），也可以先用群体智能离线搜一组初值，再交给网络微调。深度强化学习整定 PID 是同一思路的另一支；本篇以 BP / RBF 在线整定为主，强化学习放在延伸阅读。

## 方法草图

**输入**

- 转速给定 $\omega^*(k)$，以及测量或观测得到的转速 $\omega(k)$。
- 误差 $e(k)=\omega^*(k)-\omega(k)$，一阶差分 $\Delta e(k)$，二阶差分 $\Delta^2 e(k)$。
- 可选：电枢电流或 $i_q$、负载观测。让网络看见工况，而不是只看误差大小。

**模型或算法**

一种常见的小网络是三层前馈：输入取 $[\omega^*, e, \omega]$ 或 $[e, \Delta e, \Delta^2 e]$，隐层用 $\tanh$，三个输出对应三个增益。输出激活取正值区间（例如 sigmoid 再乘以量纲系数），使 $K_p,K_i,K_d$ 保持非负，并加上上下限。控制律用增量式 PID，控制量再限幅，饱和时停止积分累积。

在线学习的瞬时指标常取 $E=\frac{1}{2} e(k)^2$。电机的 $\partial \omega/\partial u$ 一般未知，课堂实现可以用 $\mathrm{sign}(\Delta\omega/\Delta u)$ 近似雅可比，或并联一个很小的辨识网络。注意用的是上一拍控制量引起的转速变化，不能只用 $\mathrm{sign}(\Delta\omega)$。PMSM 上，$u$ 是 $i_q^*$；电流内环、解耦和 SVPWM 保持常规结构，网络只动转速环。离线路线则是：用优化算法在仿真里搜索增益或网络初值，在线阶段只做小步修正。

**输出与指标**

- 阶跃给定：超调、上升时间、进入 $\pm 2\%$ 带的调节时间、稳态误差。
- 积分指标：IAE 或 ITAE。同一组曲线用同一指标比较。
- 负载阶跃：转速跌落深度和恢复时间。
- PMSM 可加转矩脉动或 $i_q$ 跟踪误差。
- 约束是否被遵守：增益是否贴边、控制量是否长期饱和、采样周期是否远小于机械时间常数。

下面是课堂用的离散草图，不是某一篇论文的训练代码。

```text
each sample k:
    e   = w_ref - w
    de  = e - e1
    dde = e - 2*e1 + e2
    if abs(u - u_prev) > eps:
        Jhat = sign((w - w_prev) / (u - u_prev))  # 上一拍控制的效果
    Kp, Ki, Kd = clamp(NN([w_ref, e, w]), 0, Kmax)
    du = Kp*de + Ki*e + Kd*dde
    u_prev = u
    u = clamp(u + du, umin, umax)     # 饱和时增量被截断
    apply u                           # 直流：电枢电压；PMSM：iq*
    update NN weights to reduce 0.5*e*e, scaled by Jhat
    e2, e1, w_prev = e1, e, w
```

1. **EDBO + BP 神经网络自适应 PID，直流电机（开放获取，2024-11-16）。** Kong 等在 *Scientific Reports* 提出增强蜣螂优化器（EDBO）与 BP 网络相结合的自适应 PID：群体搜索负责探索，BP 网络按运行状态微调 $K_p,K_i,K_d$ 和网络参数。文中网络以给定、误差和实际输出为输入，隐层 8 个 $\tanh$ 神经元，三个输出为 PID 增益。摘要给出的简化电机实验中，该控制器超调 0.5%，响应时间 0.012 s，调节时间 0.02 s，稳态误差 0.0010；另一组五台直流电机测试中，摘要记录超调 0.7%、响应时间 0.0010 s。这些数字属于该文的仿真工况，不能当成其他电机的设计指标。

## 教辅提示

**小实验。** 用一个二阶离散直流电机模型（电气一阶 + 机械一阶即可）做三组对照：手工或 Ziegler–Nichols 整定的固定 PID、只离线优化一次的 PID、上面的在线 BP-PID。工况固定为标称阶跃、转动惯量乘 2、中途阶跃负载。记录 $\omega(t)$、$e(t)$ 和 $K_p,K_i,K_d$ 的轨迹，用同一张表比较超调、调节时间、稳态误差和 ITAE。增益初值先用能稳定的固定 PID，学习率从很小开始。PMSM 不要第一步就上逆变器模型；转速环稳定后，再把控制量换成 $i_q^*$，内环仍用 PI。

**常见坑**

- 雅可比符号反了，权值更新会放大误差，表现为增益来回抽动。
- $K_i$ 没有上限、输出饱和时仍累加，负载撤掉后转速过冲。先限幅，再谈网络。
- 学习率过大，增益在一个机械周期内抖动，仿真「看起来在学习」，电流却在开关频率附近振荡。
- 只在一条阶跃上训练，换惯量就发散。至少留一个没有参与调参的负载工况做检验。
- 采样时间用错：连续 PID 公式直接放进离散逆变器，微分项会放大测量噪声。转速微分先做一阶滤波，或改用 $\Delta e$。
- PMSM 只调转速环，电流环本身不稳定或未解耦，外环再智能也跟不住。
- 把某篇摘要里的 0.5% 超调抄成自己的验收指标。对象、限幅和采样都不同，数字不可搬运。
- 神经网络 PID 不代替过流、过温、编码器和母线欠压保护。
