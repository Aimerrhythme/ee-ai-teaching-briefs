# 基于仿真数据与机器学习的直流微网电压波动抑制

日期：2026-10-29  
slug：`dc-microgrid-voltage-ml`  
关键词：直流微网，电压波动，机器学习

## 今日切入

主题队列下一条是用仿真数据和机器学习抑制直流微网的母线电压波动。直流微网没有频率，母线电压就是功率平衡的唯一"仪表"：光伏出力突变、负荷投切、恒功率负荷（CPL）接入，都会直接表现成电压的跌落、过冲和振荡。2025–2026 年的公开工作有三条能进课堂的线索：一篇综述把电压控制方法分成模型驱动、无模型和混合三类，并在带输入 LC 滤波的 Buck 变换器上对比了 TD3、PPO 与 PI、滑模、模糊控制；一篇博士论文把 DRL 控制器只放在暂态里用，稳态交回级联 PI；一篇 2026 年 9 月的论文在四源三负荷的孤岛直流微网上做带输入饱和约束的强化学习二次控制。本篇做方法速览，方便在电力电子或微网课上先跑通"仿真出数据 → 定状态与奖励 → 训练 → 与 PI 同场对比"这条闭环。

## 背景 5 分钟

**电气问题。** 一个典型的低压直流微网由若干 DC/DC 变换器把光伏、储能接到同一条母线上，负荷并联在母线上。一次控制通常是本地电压环加电流环，多源并联时再加下垂（droop）：输出电流越大，本地电压参考越低，以此按容量分摊电流。下垂的代价是母线电压随负载偏离额定值，所以要有二次控制把电压拉回、同时修正分流误差。

"电压波动"要先分清是哪一种：

- 阶跃型：负荷投切、光照骤变后的跌落与恢复，看超调、调节时间。
- 振荡型：恒功率负荷（例如带闭环控制的电机驱动、充电桩）在小信号意义下呈负增量阻抗 \( \partial v / \partial i < 0 \)，会削弱 LC 环节的阻尼，严重时母线持续振荡甚至失稳。
- 稳态偏差：下垂造成的电压偏离和各源分流不均，属于二次控制的问题。

三种问题的评价指标、适合的方法都不同，课堂作业里要先写明处理的是哪一种。

**AI 方法。** 机器学习在这里主要有两种用法。第一种是"学一个控制器"：把变换器看成环境，状态是电压误差及其积分等量，动作是占空比或电压参考的修正量，奖励按误差平方取负，用 DQN（离散占空比）、DDPG / TD3 / PPO（连续动作）训练。第二种是"学去调一个已有控制器"：保留 PI、滑模或下垂这些物理意义清楚的控制律，只让网络在线调增益、下垂系数或在暂态时接管。后一种更容易讲清安全性，也是近两年论文常走的路。无论哪种，训练数据几乎都来自仿真模型（Simulink、PLECS 或自写的平均模型），"仿真数据"本身就是方法的一部分，必须交代模型参数和扰动是怎么采样的。

## 方法草图

**输入（仿真环境）**

- 对象：先用单台 Buck（或 Boost）变换器带阻性负载加一个 CPL，母线额定电压取一个整数值（例如 48 V）。多源微网留到第二步。
- 模型：开关模型能看到纹波，但训练慢；平均模型快，适合 RL 大量回合。两种都做时，训练用平均模型，验收用开关模型，并写明。
- 扰动采样：每个回合随机抽取参考电压阶跃、输入电压扰动、负荷功率阶跃、CPL 功率比例；同时给 \(L\)、\(C\) 加 ±10% 左右的参数偏差，避免策略只记住一组参数。
- 观测量：电压误差 \(e = v_{ref} - v\)、误差积分、上一步电压、参考电压；需要时加电感电流。全部按额定值归一化。

**模型或算法**

- 基线：双环 PI（外环电压、内环电流），按教材方法整定；再加一个滑模或模糊控制作对照。
- RL 控制器：连续动作用 TD3 或 PPO，动作是占空比或占空比增量，限幅在 \([0, d_{max}]\)。奖励建议形如 \( r = -k_1 e^2 - k_2 |\Delta d| - k_3 \cdot \mathbb{1}[\,|e| > e_{lim}\,] \)，第二项抑制占空比抖动，第三项惩罚越限。
- 混合方案：稳态用 PI，误差移动平均超过阈值才切到 RL，并用迟滞带防止来回切换。
- 多源二次控制：每个源一个智能体，奖励同时含本地电压误差和与邻居的分流误差；动作必须带饱和约束，否则会出现物理上不可实现的控制量。

**输出与指标**

- 暂态：上升时间、超调量、调节时间、最大跌落。
- 稳态：RMSE、MAE、MAPE、IAE（积分绝对误差）。
- 振荡：CPL 比例逐步提高时，母线电压峰峰值或主导振荡频率的幅值；记录失稳出现时的 CPL 比例。
- 多源：各源电流与额定比例的偏差、母线电压恢复时间。
- 稳健性：训练时没见过的参数组合和扰动幅值下重测，报告指标退化多少。

下面是课堂用的离散草图，不是某一篇论文的训练代码。

```text
# environment: averaged buck model + resistive load + CPL, Ts fixed
reset(): sample v_ref step, Vin disturbance, load step, CPL share, L/C ±10%
obs = [e, integral(e), v_prev, v_ref] / V_nom
action = duty (TD3/PPO) clipped to [0, d_max]
reward = -k1*e^2 - k2*|duty - duty_prev| - k3*(|e| > e_lim)
train on averaged model; keep agent with best mean eval reward
evaluate on switching model with unseen parameter sets
compare with: dual-loop PI, SMC or fuzzy (same plant, same disturbances)
report rise / overshoot / settling / RMSE / IAE and CPL share at instability
optional hybrid: PI in steady state; switch to agent when moving-avg |e| > band
```

## 最新公开信息

1. **直流微网电压控制综述，并在带输入 LC 滤波的 Buck 上对比 TD3 / PPO（开放获取，*Energies* 2025, 18(21), 5706，发表于 2025-10-30）。** Muhammad、Obeid、Hammou、Hinaje、Gualous 把电压控制分成模型驱动（滑模、自适应下垂、MPC、无源性、ADRC、H∞）、无模型（模糊、ANN、无模型自适应、DRL）和混合三类，并逐类总结优缺点。实验部分用 MATLAB/Simulink R2024a，状态取电压误差、误差积分、延迟一步的输出电压和参考电压，动作是占空比，奖励以负的误差平方为主、另有离散奖励与越限惩罚。超参数用贝叶斯优化调：30 次评估、每次 300 个训练回合，每 20 个回合连续做 4 次评估取平均奖励。三个场景是参考电压变化、输入电压扰动、负荷功率变化（参考 48 V），对照为 PI、滑模和模糊控制。参考电压变化场景里 BO-TD3 上升时间 0.0016 s、调节时间 0.0032 s；BO-PPO 上升最快（0.0012 s）但超调较大；滑模超调最小但更慢。结论写明 BO-TD3 相对基准方法 RMSE 最多降 5.6%、MAPE 最多降 7.8%，并指出主要限制是训练计算量大。对象是单台变换器，不是多源微网；这些数字属于该文模型与参数，不能当成课程验收线。

## 教辅提示

**小实验。** 分三步，每步都和同一组 PI 对比。

1. 在 Simulink（或 Python 平均模型）里搭一台 48 V Buck，带阻性负载加 CPL。把 CPL 占总负荷的比例从 0 逐步加到 80%，只用 PI，记录母线电压开始持续振荡时的比例。这一步不用任何 AI，目的是让学生亲眼看到负增量阻抗的后果。
2. 用同一个模型做环境，训练一个 TD3 或 PPO 控制器（MATLAB Reinforcement Learning Toolbox，或 Python 的 Stable-Baselines3 加自写环境）。训练时随机化扰动和 \(L\)、\(C\)，验收时换一组训练没用过的参数。表格至少列上升时间、超调、调节时间、RMSE、IAE。
3. 做一个混合版本：稳态 PI，误差超阈值切换到智能体，比较切换带宽设得太窄时的抖动。

有余力再扩到两源并联加下垂，观察下垂系数大小与电压偏差、分流精度之间的取舍，再考虑二次控制。

**常见坑**

- 训练和验收用同一组参数与扰动。RL 很容易过拟合到一个工况，验收必须换参数。
- 动作不限幅，或只在环境里截断却不告诉智能体。占空比饱和后奖励会骗人；*Mathematics* 一文专门对比了不考虑约束的 RL 输入越限。
- 奖励只有误差平方。智能体会用高频抖动的占空比换小误差，开关模型上纹波和损耗会变差；要加动作变化惩罚。
- 用平均模型训练、却按开关模型的结论写报告，或反过来。两者必须标明。
- 把 RL 和"没整定好的 PI"比。基线 PI 要按教材方法认真整定，否则对比没有意义。
- 把文献里 5.6% 的 RMSE 降幅或 0.0016 s 上升时间抄成验收线。对象、参数和扰动都不同。
- 只看一种扰动。参考阶跃、输入扰动、负荷阶跃、CPL 比例要分场景报告。
- 只报仿真结果就说"可工程应用"。没有 HIL 或实物验证时，结论止于仿真。

**延伸阅读。** 先读 *Energies* 综述前半部分按模型驱动、无模型、混合三类梳理的方法和附录表 A1–A3，再看第 6 节 DRL 控制器的状态、动作、奖励设计。分布式二次控制和输入约束，读 *Mathematics* 一文第 2 节的系统建模和第 5 节的负荷扰动测试。混合切换的思路，看 Queen's 论文摘要中对迟滞监督机制的描述。
