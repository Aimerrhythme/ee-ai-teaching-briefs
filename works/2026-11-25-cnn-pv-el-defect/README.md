# 光伏组件 EL 图像缺陷 CNN 分类（2026-11-25）

> 主题：`cnn-pv-el-defect` · 关键词：光伏、电致发光（EL）、CNN、缺陷识别  
> 定位：教辅 / 技术速览，供课堂与课题讨论参考；不是毕业论文代写。

## 1. 今日切入

**一句话**：给光伏组件通上正向电流，电池片会像 LED 一样发出微弱的近红外光，用相机拍下来就是 **EL 图像**——隐裂、断栅、失效区在图里都表现为"该亮的地方暗了"；CNN 要学的，正是用一组**小卷积核**在整张电池片上"扫"出这些**局部的暗线、暗块**，而不是看整片亮不亮。

**为何今天写**：昨天的 `yolo-insulator-defect`（11-24）讲的是"画框"的目标检测；今天回到图像**分类**，但换成新能源侧最典型的工业视觉场景。它也正好补齐本仓光伏线：`pv-lstm-short-term`（10-26）讲功率预测、`rf-pv-inverter-fault`（11-03）讲逆变器故障，今天落到**组件本体的质量与运维**。EL 检测在组件厂出厂检验、电站进场抽检和运维排查里都很常见，专科新能源/光伏运维方向的学生最可能在实训或岗位上见到 EL 图。

## 2. 背景 5 分钟

**电气问题**：晶硅电池片在正向偏置下，注入的少数载流子发生辐射复合，发出约 1000–1200 nm 的近红外光，亮度大致反映**局部少子寿命与电流通路是否完好**。因此：
- **隐裂（microcrack）**：硅片受机械应力（运输、安装踩踏、冰雹、热循环）产生的细裂纹，EL 上是一条细暗线；初期可能不掉功率，但会在热循环中扩展，最终把一块区域**电隔离**；
- **断栅（finger interruption）**：细栅线局部断开，附近电流收集变差，表现为栅线方向的短暗条；
- **失效区（inactive / disconnected area）**：裂片后被隔离或互连失效的区域，整块发暗，直接减少有效发电面积，严重时引发热斑；
- 同时要分清**本征特征**：单晶片四角的倒角、主栅线、多晶片的晶粒纹理与晶界——它们也"暗"，但**不是缺陷**。这正是传统"阈值法"容易误判、也是需要学习型方法的原因。

**AI 方法**：EL 图像天然是灰度图，缺陷是**局部、小尺寸、方向不定**的纹理异常，这正是 CNN 的强项：卷积核共享权重、在全图滑动，对"同一种暗线出现在哪里"不敏感（平移等变），再经池化得到全局判断。Deitsch 等人（2019，见第 4 节）在公开 elpv 数据上把**手工特征 + SVM**与**端到端 CNN**做了系统对比，是本主题最经典的入门文献；近年研究则转向语义分割（逐像素标注缺陷类型）以及在标注稀缺时的**预训练 / 自监督 / 半监督**策略。

## 3. 方法草图

**输入**
- 组件 EL 整图 → 透视校正、去畸变 → 按电池片切分并统一尺寸（elpv 为 300×300 灰度图）；
- 标签：elpv 每张电池片给的是**缺陷概率** p ∈ {0, 1/3, 2/3, 1}（专家对"是否缺陷"的把握程度）+ 单晶/多晶类型；课堂上常以 p ≥ 0.5 二值化为"缺陷"。

**模型（概念级）**
```
电池片灰度图 → 逐图标准化（抹掉整体亮度差）
  → [卷积 k×k → ReLU] × L（浅层学"暗线/暗块"等局部模式，深层组合成缺陷形态）
  → 全局池化 → 全连接 → sigmoid 输出"缺陷概率"
损失：加权交叉熵（缺陷样本少，需加权或重采样）
```
- 小数据下常见做法：ImageNet 预训练权重迁移 + 旋转/翻转等数据增强（Deitsch 等即用预训练 VGG19 微调，并做大量增强）。

**评价指标**
- 准确率之外必须看**召回率**（漏掉一块隐裂片 = 带隐患的组件上了屋顶）、精确率（误判 = 多一次复检/更换成本）、F1 与 **ROC-AUC**；
- **按单晶 / 多晶分开报告**：多晶纹理复杂，误报率通常明显更高。

**输出**：每片电池片的缺陷概率 → 组件级汇总（缺陷片数量、位置）→ 判定"合格 / 复检 / 退换"，最终由质检人员确认。

**本目录附带的合成数据演示**：[`el_cnn_demo.py`](./el_cnn_demo.py)（仅依赖 numpy，本机约 15 秒）  
合成 32×32 的"EL 电池片"：亮底 + 两条竖直主栅暗线；**单晶**四角有倒角暗区，**多晶**叠加晶粒明暗斑块和若干较淡的**晶界细暗线**（非缺陷，但长得像隐裂）；每片整体亮度随机 ×0.85–1.15（模拟不同组件/注入电流）。约 30% 的片加入一种缺陷：隐裂（随机方向细暗线）、断栅（短横向暗条）或失效区（小暗块）。对比三种分类器（阈值均在**训练集**上按 F1 最大选取，测试集不参与调参）：
① 平均亮度阈值；② 逐图标准化后的像素级逻辑回归；③ 极简 CNN：8 个 5×5 卷积核 → ReLU → 全局最大池化 → 逻辑回归，手写反向传播 + Adam，60 轮。

本机（2026-11-25）运行输出——实验 A：训练 1600 张（缺陷 469），测试 600 张（缺陷 162；单晶 310 / 多晶 290）：

| 方法 | 准确率 | 召回 | 精确率 | F1 | AUC | 单晶 F1 / AUC | 多晶 F1 / AUC |
|---|---|---|---|---|---|---|---|
| 平均亮度阈值 | 0.283 | 0.951 | 0.267 | 0.417 | 0.549 | 0.422 / 0.599 | 0.412 / 0.503 |
| 像素逻辑回归 | 0.735 | 0.463 | 0.510 | 0.485 | 0.704 | 0.569 / 0.776 | 0.419 / 0.666 |
| 极简 CNN | **0.872** | **0.747** | **0.771** | **0.759** | **0.875** | **0.872 / 0.957** | **0.659 / 0.816** |

实验 B（域偏移，极简 CNN，另生成 600 张纯多晶测试片）：

| 训练数据 | 准确率 | 召回 | 精确率 | F1 | AUC |
|---|---|---|---|---|---|
| 只用单晶训练（1600 张） | 0.282 | 1.000 | 0.282 | 0.440 | 0.548 |
| 单晶 + 多晶混合训练 | 0.702 | 0.692 | 0.480 | 0.567 | 0.776 |

读法：
1. **"看整体暗不暗"基本无效**（AUC 0.549，接近随机）：缺陷只让一小块变暗，而片与片之间的整体亮度差（±15%）远大于它；按 F1 选出的阈值退化成"几乎全判缺陷"（召回 0.951、准确率仅 0.283）——这也说明**只报召回率会被骗**。
2. **像素逻辑回归**有进步（AUC 0.704），但它给每个像素位置一个固定权重，缺陷出现在哪里、朝哪个方向都是随机的，它学不到"一条暗线"这种**与位置无关的形状**。
3. **极简 CNN** 只有 8 个卷积核，AUC 就到 0.875、F1 0.759：卷积核在全图滑动、全局最大池化只问"哪里出现过这种局部模式"，正好匹配缺陷的本质。
4. **多晶明显更难**（CNN 单晶 AUC 0.957 vs 多晶 0.816）：晶界细暗线和隐裂长得像，这与 Deitsch 等在真实 elpv 数据上的观察一致（多晶片的纹理差异大，是更难的测试）。
5. **域偏移**：只用单晶训练的模型拿去测多晶，几乎把所有片都判成缺陷（召回 1.000、精确率 0.282、AUC 0.548）——它从没见过晶粒纹理，就把一切陌生的暗纹当缺陷。训练集必须覆盖实际要检的组件类型。（实验 B 用的是另一批纯多晶测试片，数字与实验 A 的"多晶"列不完全相同属正常。）

合成图远比真实 EL 简单，数字只用于课堂讲清概念，不代表任何真实模型在 elpv 或产线数据上的性能。

## 4. 最新公开信息

1. **elpv-dataset 公开数据集**（zae-bayern/elpv-dataset；配套会议论文 Buerhop-Lutz 等，*A Benchmark for Visual Identification of Defective Solar Cells in Electroluminescence Imagery*，EU PVSEC 2018，DOI 10.4229/35thEUPVSEC20182018-5CV.3.15）  
   仓库 README：**2,624 张** 300×300 8 位灰度电池片图像，取自 **44 块**组件，已做尺寸/透视归一化并消除镜头畸变；每张标注缺陷概率（0–1）与单晶/多晶类型，可 `pip install elpv-dataset` 后用 `load_dataset()` 直接加载。按仓库 `labels.csv` 统计（2026-11-25）：p=0 有 1508 张、p=1/3 有 295 张、p=2/3 有 106 张、p=1 有 715 张；单晶 1074 张、多晶 1550 张。数据许可为 **CC BY-NC-SA 4.0**（非商用、相同方式共享），课堂使用没问题，商业项目需注意。  
   https://github.com/zae-bayern/elpv-dataset

2. **Automatic Classification of Defective Photovoltaic Module Cells in Electroluminescence Images**（Sergiu Deitsch, Vincent Christlein, Stephan Berger, Claudia Buerhop-Lutz, Andreas Maier, Florian Gallwitz, Christian Riess；arXiv:1807.02894；期刊版 *Solar Energy* 185 (2019) 455–468，DOI 10.1016/j.solener.2019.02.067）  
   elpv 的配套方法论文：对比"手工特征（KAZE/VGG 等描述子）+ SVM"与"端到端 CNN（GPU）"两条路线。按 75%/25% 分层划分，用 **1,968 张**训练、**656 张**测试；摘要报告 CNN 平均准确率 **88.42%**，SVM **82.44%**（但可在任意硬件上运行）。文中还给出：CNN 训练近 5 小时、SVM 约 30 分钟；多晶片上 CNN 的 AUC 比 SVM 高近 11%。课堂上最适合用来讲"精度 vs 硬件成本"的工程取舍。  
   https://arxiv.org/abs/1807.02894 · https://doi.org/10.1016/j.solener.2019.02.067

3. **A Large-scale Evaluation of Pretraining Paradigms for the Detection of Defects in Electroluminescence Solar Cell Images**（David Torpey, Lawrence Pratt, Richard Klein；arXiv:2402.17611，2024-02）  
   把任务从"整片分类"推进到**语义分割**（逐像素标出缺陷与本征特征），系统比较监督分割、半监督（CCT、U2PL）和自监督（SimCLR、MoCo v2）预训练，以及域内 / 域外（ImageNet、COCO）预训练。摘要结论：COCO 上的监督预训练、ImageNet 上的自监督预训练和半监督 CCT 在 mIoU 上**统计意义上相当**，并刷新了该任务的最好结果；作者还公开了 **22,000 张**无标注 EL 图和 **642 张**带分割标注的 EL 数据（含 15 类缺陷、13 类本征特征）。文中也指出缺陷类比本征特征类更难——样本少且目标小。适合给本科/专升本讲"标注稀缺时怎么办"。  
   https://arxiv.org/abs/2402.17611

## 5. 教辅提示

**可布置的小实验（2–4 学时）**
1. 运行 `el_cnn_demo.py`，先让学生预测三种方法谁最好、为什么，再看结果；重点讨论"平均亮度阈值为什么召回很高却毫无用处"。
2. 把 `tiny_cnn` 的卷积核数 `F` 从 8 改为 2 和 16、核大小 `k` 从 5 改为 3 和 7，观察 AUC 变化，讨论"感受野要和缺陷尺寸匹配"。
3. 把隐裂的变暗系数（`img[y, x] *= 0.5`）调到 0.7，模拟更细微的隐裂，看召回下降多少——对应真实 EL 中"轻微隐裂最难判"。
4. 去掉 `standardize()`（直接用原图），比较 CNN 结果，理解逐图标准化对消除注入电流/曝光差异的作用。
5. 本科 / 专升本延伸：`pip install elpv-dataset` 加载真实数据，以 p ≥ 0.5 为缺陷，用 PyTorch/Keras 微调一个 ImageNet 预训练 ResNet18，**分单晶/多晶**报告 F1 与 AUC，并与 Deitsch 等的结果对照；注意划分时保持类别分层。

**常见坑**
- **把本征特征当缺陷**：单晶倒角、主栅、多晶晶界都是"暗"的，若训练集多晶样本少，模型会大面积误报（见实验 B）。
- **数据泄漏**：同一块组件切出的电池片、或同一片的增强副本分别进了训练集和测试集，指标虚高；更严格的做法是**按组件分组**划分。
- **忽视软标签**：elpv 的 p=1/3、2/3 代表专家也不确定，直接硬二值化会引入标签噪声；可尝试回归 p 或丢弃中间样本做对比实验。
- **只看准确率**：缺陷片约占 3 成时，"全判正常"也有约 70% 准确率。
- **把分类结果当结论**：EL 只反映电学通路，是否影响功率还需 I–V 曲线/功率测试佐证；模型输出只是复检线索。
