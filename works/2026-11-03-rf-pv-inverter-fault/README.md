# 基于随机森林的光伏逆变器故障诊断仿真

日期：2026-11-03  
slug：`rf-pv-inverter-fault`  
关键词：随机森林，光伏逆变器，故障诊断

## 今日切入

主题池下一条是用随机森林（Random Forest, RF）做光伏并网逆变器的故障诊断。今天值得写，是因为 2026-10-21 刚有一份开源复核工作把一个常用公开数据集上的「99% 准确率」拆开看：在常见的随机切窗划分下，模型很大程度上是在**认出「这段数据来自哪一次实验」**，而不是认出故障本身；换到另一种运行模式测试，宏平均 F1 只剩 0.15–0.52。这正好给课堂一个比「调参刷分」更重要的主题：**故障诊断实验怎么划分数据才算数**。本篇按「仿真/公开数据 → 特征 → RF → 诚实评估」的顺序做方法速览。

## 背景 5 分钟

**电气问题。** 两级式三相并网光伏系统通常是「光伏阵列 → Boost/MPPT → 直流母线 → 三相电压源逆变器（6 只 IGBT）→ 滤波 → 电网」。常见故障分几层：

- **功率器件**：IGBT 开路（驱动丢失、键合线脱落）或短路；开路后对应相电流出现半波缺失、直流分量，系统常常还能“带病运行”，所以更需要诊断。
- **直流侧与阵列**：母线电容老化、阵列失配 / 局部阴影、MPPT 控制异常。
- **交流侧与测量**：电网电压异常、反馈传感器故障、锁相环失步。

课堂上要先讲清：**检测**（有没有故障）、**分类**（哪一类故障）、**定位**（哪只开关）是三件难度递增的事，指标和数据要求都不同。

**AI 方法。** 随机森林是很多棵决策树的投票：每棵树用自助采样（bootstrap）的样本训练，每次分裂只在随机抽取的部分特征里找最优切分，最后多数表决。它适合这个题目的原因很朴素：

1. 特征是表格形式的统计量（均值、有效值、谐波含量、直流分量），树模型对量纲不敏感，不必精调网络结构。
2. 自带特征重要性，便于和电路机理对照（例如开路故障时某相电流均值偏移最重要，说得通）。
3. 训练快、推理轻，适合讲「可嵌入」的诊断思路。

它的短板同样要讲：特征工程决定上限；对没见过的工况（换辐照、换运行模式）外推能力有限；类别不平衡时总体准确率会骗人。

## 方法草图

**输入（课堂尺度）**

- **仿真路线**：在 MATLAB/Simulink（或 PLECS、Python 开关函数模型）搭两级式三相并网逆变器，按开关逐只设置开路（门极信号恒为 0），再做双管开路组合；改变辐照、温度、负载，并叠加不同信噪比的噪声。
- **公开数据路线**：GPVS-Faults（Bakdi 等，2020，CC BY 4.0）是实验室并网光伏微网的实测数据，16 个文件对应 F0（无故障）与 7 类故障在 MPPT / IPPT 两种模式下各一次实验，含 \(I_{pv}\)、\(V_{pv}\)、\(V_{dc}\)、三相电流电压和正序幅值 / 频率估计；故障在实验中途人为注入，采样约 10 µs 量级（以数据说明为准）。
- **切窗与特征**：按一个工频周期（50 Hz 时 20 ms）切窗，每窗算均值、有效值、峰峰值、偏度、各相电流直流分量、THD 或低次谐波幅值、三相不平衡度、\(V_{dc}\) 纹波等。
- **标签**：仿真里故障时刻已知，直接打标签；公开数据里要按**故障起始时刻**打标签，故障前的窗应标为正常，而不是整条记录都标成该故障。

**模型或算法**

基线 A — **阈值规则**：相电流直流分量或 \(V_{dc}\) 纹波超过阈值判故障，给出检测延迟与误报率。  
基线 B — **单棵决策树 / 逻辑回归**：同一特征集，看 RF 的集成到底带来多少。  
主模型 — **随机森林**：`n_estimators` 100–300，`max_features` 取 `sqrt`，类别不平衡时用 `class_weight="balanced"`；先做二分类检测，再做多分类或开关定位（两级结构）。  
进阶 — 降维（PCA / 自编码器）后再接 RF，对比精度与推理时间。

**输出与指标**

- 检测：准确率、召回率（漏报代价高时优先）、误报率、检测延迟（从故障注入到第一次报警的时间）。
- 分类 / 定位：宏平均 F1、混淆矩阵、每类召回率。
- **划分方式必须写在指标旁边**：随机切窗、按实验（记录）分组、跨运行模式 / 跨工况，三种结果往往相差很大。

课堂用草图（概念级，不是某一篇论文的训练脚本）：

```text
for each run r (simulation case or GPVS file):
    onset = known fault time (sim) or estimated onset (data)
    windows = split(signals[r], 20 ms)
    for w in windows:
        x = features(w)              # mean, RMS, DC offset per phase, THD, Vdc ripple ...
        y = fault_type[r] if t(w) >= onset else "normal"

# honest splits (report all three)
S1 = random window split               # optimistic, leaks run identity
S2 = GroupKFold by run                 # unseen recordings
S3 = train on mode A, test on mode B   # unseen operating mode

model = RandomForest(n_estimators=200, max_features="sqrt", class_weight="balanced")
report macro-F1, per-class recall, detection delay for S1/S2/S3
sanity check: train/test only on pre-onset windows -> should be ~chance; if high, labels leak
```

## 最新公开信息

1. **GPVS-Faults 上的「泄漏感知」复核（开源代码，Zenodo 发布于 2026-10-21，MIT 许可）。** Khandoker Samiul Hoque 把 GPVS-Faults 的 16 段记录切成 20 ms 窗、提 52 个统计特征加 5 个物理特征，分四组实验对比。按 README 汇报的五次随机种子均值：常见协议（整条记录打同一标签 + 随机划分）下随机森林宏平均 F1 为 0.999–1.000；**只用故障发生前的窗**照样得 1.000，说明模型认的是记录而不是故障；改用估计的故障起始时刻打标签后，随机划分下 RF 为 0.991；**训练 MPPT、测试 IPPT（及反向）**时各模型降到 0.15–0.52，F1 与 F3 两类几乎跨模式认不出；用各段自身无故障基线做参考的特征帮助最大。作者注明：只有一台实验台，故障起点为估计值，论文仍在准备中。  
   https://github.com/KhandokerSamiulHoque/gpvs-fault-detection  
   https://doi.org/10.5281/zenodo.23537370

2. **同一数据集上的 RF / DT / KNN / LR 与降维对比（开放获取，*Electronics* 2025, 14(14), 2916，发表于 2025-07-21）。** Tufail 与 Sarwat（佛罗里达国际大学等）把 GPVS-Faults 做成「健康 / 逆变器故障」二分类（272,727 条、14 个输入特征），标准化后按 80:20 随机划分；全特征 RF（100 棵树）测试准确率 0.9987、F1 0.9986，训练约 36.47 s；PCA 或自编码器降到 8 维后 RF 约 0.99，逻辑回归在 PCA 后降到约 0.93。文中相关性分析显示 \(V_{pv}\)、\(I_{pv}\) 与标签相关最强。适合拿来和第 1 条并排读：**同一数据、同一算法，划分方式不同，结论就不同**。  
   https://www.mdpi.com/2079-9292/14/14/2916  
   https://doi.org/10.3390/electronics14142916

3. **用直流母线信号 + 随机森林做逆变器开关开路诊断（*IJPEDS* 第 16 卷第 4 期，2025-12）。** Vu 与 Nguyen 提出两步法：先只用直流母线信号由 RF 检测有无开路故障，再加入交流输出电流定位故障开关；基于仿真数据，摘要报告检测可达最高准确率、加入母线电流后定位准确率明显提升，并提到电磁场信号用于实际部署的潜力。适合作为「检测 → 定位」两级结构的仿真范例。  
   https://doi.org/10.11591/ijpeds.v16.i4.pp2178-2185

## 教辅提示

**小实验（由易到难）**

1. **仿真定位。** 在 Simulink 三相逆变器上逐只设置 T1–T6 单管开路，按周期切窗，提各相电流均值与有效值，训练 RF 做 7 类（正常 + 6 开关）分类；画特征重要性，让学生解释为什么某相电流直流分量最关键。
2. **噪声与工况。** 同一模型在 3 种辐照、2 种信噪比下测试，只在一种工况训练，观察准确率怎么掉。
3. **划分对照（本篇重点）。** 用 GPVS-Faults 依次做随机切窗、按记录分组、跨 MPPT/IPPT 三种划分，固定特征和超参，填一张三列结果表；再做「只用故障前窗口」的检查，体会标签泄漏。

**常见坑**

- 整条记录统一打故障标签，故障注入前的正常段也被标成故障，模型学到的是记录差异。
- 同一条记录相邻窗高度相关，随机划分等于让测试集「见过」训练数据。
- 只报总体准确率，掩盖少数类和难类（跨模式下某些故障几乎全错）。
- 标准化用全部数据的均值方差，测试信息泄漏进训练。
- 把 99.87% 之类的文献数字当课程验收线；数据、划分、类别定义不同，数字不可比。
- 仿真里的开路故障「过于干净」，迁到实测数据就失效；要加噪声、死区和采样抖动再评估。

**延伸阅读。** 先读 *Electronics* 2025 一文第 2 节了解 GPVS-Faults 实验台与特征，再打开第 1 条仓库的 README 和 `results/tables.md` 对照不同划分的结果；开关级定位的思路看 *IJPEDS* 一文。GPVS-Faults 原始说明和引用文献见 Mendeley Data 页面。
