# 油浸式变压器 DGA + XGBoost 诊断

日期：2026-11-13  
slug：`xgb-dga-transformer`  
关键词：DGA，变压器，XGBoost，油色谱，IEC 三比值，特征重要度

## 今日切入

主题池下一条把「传统经验规则」和「可复现的机器学习流水线」接到同一节变压器运维课里：油浸式变压器内部发生局部放电、电弧或过热时，绝缘油和纸会分解出氢气、甲烷、乙烷、乙烯、乙炔等特征气体，溶解在油里。运维上最常用的解读方法是 IEC 三比值（以及罗杰斯比值、杜瓦尔三角形、IEEE 特征气体法），但比值一旦落在编码表的空档，就会给出「无法判断 / 无故障」——这正是课堂上最值得先演示的局限。今天写它，是因为主题池的原始参考（arXiv:2110.11467）用同一批公开 DGA 样本，把传统方法和 XGBoost 放在同一张表里对比，数字很适合当主线：**规则法会空码，树模型能给出类别，但少数类（中温过热 T2）仍然容易被总体准确率掩盖。** 本篇按「产气机理与三比值 → 用公开样本训练 XGBoost → 用特征重要度回对照机理」做方法速览。

## 背景 5 分钟

**电气问题。** 油纸绝缘在电应力和热应力下会裂解。六类常见内部故障与优势气体大致对应：局部放电（PD）以氢气为主、甲烷次之；低能放电（D1）出现乙炔和氢气；高能放电 / 电弧（D2）乙炔显著，并常伴乙烯；低温过热 T1（约 300 °C 以下）多见甲烷、乙烷；中温过热 T2（约 300—700 °C）乙烯升高；高温过热 T3（约 700 °C 以上）乙烯占优，乙炔也可能出现。一氧化碳、二氧化碳则提示固体绝缘（纸）是否卷入。IEC 60599 把这六类翻译成三个基本比值——C₂H₂/C₂H₄、CH₄/H₂、C₂H₄/C₂H₆——按区间组合编码；罗杰斯四比值、多南堡比值走类似思路，杜瓦尔三角形则把甲烷、乙烯、乙炔的相对含量投到平面分区，IEEE C57.104 的特征气体法看各气体占总烃的百分比。这些规则的共同短板是：区间是硬边界，真实样本经常落在「无对应编码」或两类交界处；有载分接开关（OLTC）窜油还会让乙炔偏高，看起来像放电。

**AI 方法。** 把一次油色谱化验看成一个多分类样本：输入是五种（或七种，加上 CO、CO₂）气体浓度，以及由它们算出的比值、对数比值；输出是 PD / D1 / D2 / T1 / T2 / T3（有的数据集把 T1 与 T2 合并）。XGBoost 是梯度提升树：每棵新树拟合前面所有树的残差，分裂时按增益选择特征，训练结束后可以直接读出特征重要度。对专科学生，最重要的直觉是：**模型并不是在「发明」新的故障物理，而是在学习这些气体和比值怎样组合才能把六类分开；如果重要度最高的特征与产气机理一致（例如乙炔相关特征支撑放电类、乙烯相关特征支撑高温过热），解释就站得住；如果总准确率很高、少数类却经常错，说明还没有真正学会。**

## 方法草图

**输入（课堂尺度）**

- **样本**：公开 DGA 记录，每条至少含 H₂、CH₄、C₂H₆、C₂H₄、C₂H₂ 的浓度（通常为 µL/L 或 ppm）和故障标签。主题池原始参考使用 376 条公开样本（239 条来自埃及电网公开数据，137 条来自文献汇编），六类数量为 PD 42、D1 67、D2 113、T1 80、T2 21、T3 53——T2 明显偏少。IEC TC 10 是另一份常被引用的基准集，部分平台（如 IEEE DataPort）还提供经整理的训练 / 测试表，但下载常需登录，课堂上应优先用已获许可、可随实验报告一并交出的数据。
- **传统基线**：对每条样本计算三个 IEC 比值，查编码表得到类别或「无法判断」；对照杜瓦尔三角形、（可选）IEEE 特征气体法。重点统计「空码率」和各类召回，而不是只报「判对了几个」。
- **机器学习特征（由易到难）**：① 五种气体浓度（可先 `log1p`，因为浓度跨数量级）；② 三个 IEC 比值（分母为 0 时要约定一个很小的正数，避免无穷大）；③ 常用对数比值，如 ln(C₂H₂/C₂H₄)、ln(CH₄/H₂)、ln(C₂H₄/C₂H₆)。课堂第一轮不必上论文里的 ITD / EMD 特征提取。
- **划分**：**分层**交叉验证（如 Stratified 5 折）。T2 只有 21 条，随手做一次 85:15 随机划分，测试集里可能只剩两三条，单个错分就会让该类指标大起大落。

**模型或算法**

基线 — IEC 三比值、杜瓦尔三角形（把「无法判断」单独计为一类结果）。  
模型 — XGBoost 分类器（主题指定）。  
对照 — 决策树、随机森林；可选逻辑回归作为线性下限。  
统一设置 — 树模型对单调变换不敏感，但比值特征仍建议在训练集上检查极端值；超参数先用保守默认值（例如限制树深），比的是「规则 vs 数据驱动」而不是「谁调参更狠」。类别不平衡可先用 `class_weight` / 样本权重，不必一上来就上 SMOTE。

**输出与指标**

- **宏平均 F1** 和各类召回 / 精确率，必须看混淆矩阵，尤其是 D1↔D2、T1↔T2↔T3 这些「能量或温度相邻」的类别。
- **总体准确率只作附注**：在 376 条里 D2 约占 30%、T2 只约占 5.6%，准确率会被多数类抬高。
- **特征重要度**：用 XGBoost 的增益（gain）或权重（weight）排序，把前几名特征写在黑板右侧，左侧写对应的产气机理，看两者是否同向。
- **空码对照表**：同一批测试样本上，IEC / 罗杰斯给出「无法判断」的条数 vs XGBoost 给出的类别——这是本课的核心对照，不是为了宣布「机器学习已经取代标准」。

课堂用草图（概念级，不是某一仓库的训练脚本）：

## 最新公开信息

1. **主题池原始参考：Sami、Bhuiyan，「Power Transformer Fault Diagnosis with Intrinsic Time-scale Decomposition and XGBoost Classifier」，arXiv:2110.11467（2021-10）。** 先按偏度排序一批 DGA 参数（气体浓度与常用比值），再做本征时间尺度分解（ITD）提取本征旋转分量（PRC），用 XGBoost 选出最优的 24 维特征后分类。数据为公开的 376 条、六类故障，随机 333 / 43 划分。提出方法总体准确率 95.35%，各类 F1 大多接近 1，但测试集里 T2 只有 3 条、灵敏度 66.67%、F1 为 0.8——总体高分并不能掩盖少数类偏弱。同一测试划分上，杜瓦尔三角形 62.79%、罗杰斯四比值 44.19%、IEC 方法 46.51%；文中还举例：IEC 与罗杰斯会给出 UD / NF（无法判断或无故障），杜瓦尔在边界区分错。因类别不平衡，作者另做了 SMOTE + 5 折交叉验证，提出方法 Cohen's Kappa 0.91、F1 0.92，略高于他们对照的分层 EMD + 层次 XGBoost（0.89 / 0.90）。课堂用法：主结论可直接搬上讲台（规则空码、总体准确率与 T2 召回要分开看）；ITD 特征提取作为进阶选读，第一轮实验用原始气体和比值即可。  
   https://arxiv.org/abs/2110.11467

2. **域偏移（换一台变压器，模型可能失效）：Mahmoodiyan、Ahang、Abbasi、Najjaran，「Feature-Weighted MMD-CORAL for Domain Adaptation in Power Transformer Fault Diagnosis」，arXiv:2505.14896（2025-05）。** 源域来自文献汇编的埃及与印度公用事业样本（343 条，增强后 887 条），目标域为 IEC TC 10（140 条），五类故障（T1 与 T2 合并）。特征包括各气体比值和 ln(C₂H₄/C₂H₆)、ln(C₂H₂/C₂H₄)、ln(CH₄/H₂) 等，正是课堂上会用到的那组量；源、目标之间平均 KL 散度约 0.698，说明分布并不相同。作者用 K-S 统计量为偏差更大的特征加权，再对齐 MMD 与 CORAL（MCW），相对「源域预训练再在目标域微调」准确率平均高 7.9%，相对不加特征加权的 MMD-CORAL 高 2.2%；目标域训练样本只占 30% 时，MCW / 微调 / MC 的准确率分别为 85.9%、82.1%、85.0%，用到 90% 时则为 95.3%、86.4%、92.1%。课堂启示：在公开汇编集上得到 95% ，不能直接宣称对变电站里的另一台变压器同样有效；跨数据源评价比再堆一个分类器更重要。该方法把比值做成二维图像再送入 CNN，实现明显重于本课的树模型实验，当作「问题意识」即可。  
   https://arxiv.org/abs/2505.14896

3. **2026 年仍在补传统规则的软边界：Nguyen、Le、Phung，「Optimized Fuzzy Logic Approach with the IEEE Key Gas Method for Diagnosing Power Transformer Faults Using Dissolved Gas Analysis」，arXiv:2608.18133（2026-07）。** 针对 IEEE 特征气体法阈值过硬、一氧化碳与纸绝缘劣化绑定后容易误判等问题，把特征气体法与模糊逻辑结合（FL-KGM），把 CO 与 CO₂ 分开处理，并重设隶属度与规则。文中指出传统特征气体法在复杂或边界样本上的不结论率可高达约 50%，在若干场景准确率低于 85%；作者用真实 DGA 数据评估，提出方法在较完整测试中总体准确率可达 98.6%（例如高温过热 F3：74 条中 73 条正确），并优于文中对照的若干模糊—IEC / 罗杰斯 / 多南堡模型（多不超过 90%）。另有 15 条随机抽检：传统特征气体法偏弱，提出方法全部判对。课堂启示：2026 年仍有工作在给「硬阈值规则」加软边界，说明规则并未被淘汰；同时也要提醒——98.6% 与文献 1 的 95.35% 来自不同标签体系、不同划分，**不能横比谁更准**，回到原文看样本与类别定义。  
   https://arxiv.org/abs/2608.18133

现行标准方面，课堂应指向 IEC 60599:2022（运行中充矿物油电气设备：溶解气体与游离气体分析的解释导则）和 IEEE Std C57.104-2019（矿物油浸变压器产气解释导则），以标准文本为准，不要用二手表替代。

## 教辅提示

**小实验（由易到难）**

1. **先让规则「失败」。** 手算或编程实现 IEC 三比值，在公开样本上统计：判对、判错、无法判断各占多少，并把空码样本的三个比值标在数轴上，看它们是落在区间缝里，还是分母接近零。
2. **杜瓦尔对照。** 同一批样本画杜瓦尔三角形散点，观察边界点和空码点在三角形里的位置；讨论为什么图形法往往比纯编码表少一些「无结论」。
3. **三模型对比。** 用原始五种气体（可加三个比值）训练决策树、随机森林、XGBoost，分层 5 折交叉验证，报宏 F1、各类召回和混淆矩阵；把 IEC 空码样本单独列出来，看树模型给了什么类别。
4. **重要度对机理。** 画出 XGBoost 特征重要度，对照「乙炔—放电、乙烯—高温过热、氢 / 甲烷—局部放电或低温」的产气规律；若某一与机理无关的组合特征异常靠前，检查是否由零浓度、量纲或泄漏划分造成。
5. **进阶讨论。** （a）不用分层、不做类别计量，只报总体准确率，看结论被抬高多少；（b）把测试集换成另一来源（例如从文献汇编改到 IEC TC 10），直接套用原模型，体会文献 2 所说的域偏移；（c）讨论 OLTC 窜油导致乙炔升高时，模型会不会系统性误判为放电。

**常见坑**

- 只报总体准确率：文献 1 测试集 T2 仅 3 条，灵敏度 66.67%，但平均准确率仍写着 95.35%。
- 随机而非分层划分，少数类在测试集中「时有时无」。
- 比值为零或分母为零，直接相除得到 inf / NaN，树模型或标准化会悄悄把这些样本丢掉。
- 把不同论文的 95%—98% 横比：六类与五类（T1、T2 合并）、随机单次划分与交叉验证、是否包含「无故障」类，任务并不相同。
- 把汇编自多篇文献的标签当成金标准：不同作者对边界故障的命名可能不一致。
- 用训练集统计量之外的信息做预处理，或先过采样再划分，造成泄漏。
- 把 XGBoost 的输出当作可以下令停电或安排吊芯的依据——它只是油色谱解释的辅助分类器，还须结合产气速率、运行工况和电气试验。

**延伸阅读。** 先读文献 1 的数据表、Table IV（规则空码例句）和 Table V（与 IEC / 杜瓦尔 / 罗杰斯的对照），再读文献 2 的源域 / 目标域设置，建立「换数据源就要重新验证」的意识。规则与模糊软边界可浏览文献 3 的问题动机，不必在专科课上复现全部隶属度。可与 11-03「光伏逆变器随机森林故障诊断」、11-11「微网逆变器开关故障 ML 检测」、11-12「配网短路故障分类与定位」对照：同是故障分类，DGA 是稀疏的化学特征、不是短窗电压电流波形，对时延几乎没有保护级要求，但对类别不平衡和跨台域偏移更敏感。
