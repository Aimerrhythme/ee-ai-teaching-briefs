# 智能电表窃电检测 CNN 课堂案例（2026-11-23）

> 主题：`cnn-electricity-theft` · 关键词：窃电检测、CNN、智能电表、不平衡分类  
> 定位：教辅 / 技术速览，供课堂与课题讨论参考；不是毕业论文代写。

## 1. 今日切入

**一句话**：把一户用户的"日用电量"序列按周折成一张 *周 × 星期* 的小矩阵，用卷积核去看"同一个星期几在不同周之间是否还像自己"——周期性被破坏，往往就是计量被动了手脚的信号；同时用这个案例讲清楚：**窃电样本只占 1 成不到时，准确率几乎没有意义**。

**为何今天写**：上周的 `seq2point-nilm`（11-06）和 `iforest-pmu-anomaly`（11-16）分别讲了"从电表数据里看电器"和"无监督找异常"，而窃电检测是营销稽查岗位最常见的**有监督 + 极不平衡**分类问题；它又恰好是 CNN 不只用于图像的一个好例子——把一维时序"折"成二维，就能让卷积同时看到"日间"和"周间"两种邻域关系。

## 2. 背景 5 分钟

**电气问题**：线损分为技术线损（导线、变压器发热）和**非技术线损**（NTL），后者主要来自窃电、计量故障和抄表/账务错误。常见窃电手段包括绕越电表、改接线、篡改或干扰计量装置等，在用电数据上的表现通常是：从某一天起用量明显下降、波动规律消失、出现大段零值或"平得不自然"的读数。传统做法依靠线损率异常台区排查 + 现场稽查，人工成本高、命中率有限；智能电表普及后，供电企业手上有了每户逐日甚至 15 min 级的数据，自然想用数据先"圈出嫌疑户"再派人去查。

**AI 方法**：Zheng 等人（IEEE TII 2018）在国家电网公开的约 4.2 万户、1035 天日用电数据上提出 Wide & Deep CNN：Wide 分支（全连接）看一维全局特征，Deep 分支把日序列按**周**排成二维矩阵后做卷积，用来捕捉"正常用户有周期、窃电用户周期被破坏"的差异。之后的工作大多沿着两条线改进：一是**处理类别不平衡**（欠采样集成、过采样、代价敏感损失），二是换更强的时序/图模型或考虑部署约束（隐私、算力）。课堂上最值得讲透的是前者：窃电户在该数据集里约占 8.5%，一个"全部判正常"的模型准确率就有 91% 以上。

## 3. 方法草图

**输入**
- 每户 `W` 周 × 7 天的日用电量矩阵（缺失值插补后）；
- 每户除以自身均值做归一化——模型只看"用电形状"，不因用量大就被怀疑。

**模型**
- 课堂最简版（本目录脚本）：固定的 3×3 卷积核（周间差分、日间差分、局部均值等）+ ReLU + 全局均值/最大池化 → 逻辑回归。这是 CNN 前向结构的"手工版"，**卷积核不训练**，便于学生先看懂每个通道在测什么；
- 进阶版：PyTorch 里用 `Conv2d` 让卷积核可训练，或复现 Wide & Deep（1D 全连接分支 + 2D 卷积分支拼接）。

**不平衡处理（本篇重点）**
- 评价：主看 **AUC**（与阈值无关）、**召回率**（漏掉的窃电户有多少）和**精确率**（派出去稽查的有多少是真的），辅以 MAP@k（"前 k 个嫌疑户里命中多少"，最贴近稽查派单）；
- 训练：类别加权（窃电样本权重 ≈ 正常/窃电 样本数之比）、随机欠采样 + 集成（见第 4 节文献 1）、过采样。

**输出**：每户的窃电概率（嫌疑分数），按分数排序生成稽查清单；阈值由"稽查人力能查多少户"决定，而不是固定 0.5。

**本目录附带的合成数据演示**：[`theft_cnn_demo.py`](./theft_cnn_demo.py)（仅依赖 numpy，约 1 秒跑完）  
4000 户、12 周日用电合成数据，窃电约 9%；窃电从随机某一周开始，按四种方式之一篡改读数（整体按比例少计 / 每天随机少计 / 抹平成常数 / 随机日归零）。3000 户训练、1000 户测试。本机（2026-11-23）运行输出：

| 方法（测试 1000 户，窃电 84 户 = 8.4%） | 准确率 | 召回 | 精确率 | AUC |
|---|---|---|---|---|
| 全部判"正常"（哑分类器） | 0.916 | 0.000 | — | 0.500 |
| 1D 原始序列 + 逻辑回归 | 0.986 | 0.881 | 0.949 | 0.961 |
| 2D 卷积特征 + 逻辑回归 | 0.989 | 0.881 | 0.987 | 0.999 |
| 2D 卷积特征 + 类别加权 | 0.981 | 0.988 | 0.822 | 0.999 |

读法：① 哑分类器一个窃电户都没抓到，准确率却有 91.6%——这就是"不平衡时别看准确率"的最直观证据；② 2D 卷积特征的 AUC 高于直接把 84 个数丢给逻辑回归，说明"周间对比"确实是有用的归纳偏置；③ 类别加权后**准确率反而下降**，但召回从 0.881 升到 0.988，代价是精确率下降（误派稽查变多）——到底选哪个，取决于漏查一户和白跑一趟各自的成本。合成窃电模式比真实情况"干净"得多，数字只用于课堂对比趋势，不代表真实数据上的性能。

## 4. 最新公开信息

1. **An Ensemble Deep Convolutional Neural Network Model for Electricity Theft Detection in Smart Grids**（Hossein Mohammadi Rouzbahani, Hadis Karimipour, Lei Lei；arXiv:2102.06039，2021-02）  
   提出集成深度 CNN（EDCNN）：第一层先用**随机欠采样 bagging** 处理数据不平衡，再在每个子集上训练深度 CNN，最后投票集成；评价同时报告 AUC、精确率、召回、F1 和准确率。正好对应本篇"不平衡处理 + 多指标评价"的教学重点，可作为"类别加权"之外的第二种思路给学生对照。  
   https://arxiv.org/abs/2102.06039

2. **国家电网（SGCC）公开窃电数据集 + Wide & Deep CNN**（Zibin Zheng, Yatao Yang, Xiangdong Niu, Hong-Ning Dai, Yuren Zhou，*Wide and Deep Convolutional Neural Networks for Electricity-Theft Detection to Secure Smart Grids*，IEEE TII, 14(4):1606–1615, 2018, DOI 10.1109/TII.2017.2785963）  
   数据仓库 README 说明：数据来自国家电网公司，含 42,372 户在 1035 天（2014-01-01 至 2016-10-31）的日用电量，分卷压缩下载，使用时需引用上述论文。这是本主题最常用的公开基准，本篇"按周折成二维矩阵"的思路即源于该文。课堂使用时提醒学生：数据含缺失与异常值，需先做插补与截断。  
   https://github.com/henryRDlab/ElectricityTheftDetection · https://doi.org/10.1109/TII.2017.2785963

3. **Towards Secure and Scalable Energy Theft Detection: A Federated Learning Approach for Resource-Constrained Smart Meters**（Diego Labate, Dipanwita Thakur, Giancarlo Fortino；arXiv:2602.16181，2026-02）  
   较新的方向：不把用户数据集中上传，而是用**联邦学习**在多个客户端本地训练轻量 MLP（适配低算力电表），并在本地模型更新上加高斯噪声做基本的差分隐私；实验同样基于上面的 SGCC 数据集，在 IID 与非 IID（按标签划分）两种数据分布下评估准确率、精确率、召回和 AUC。适合给专升本/本科学生延伸讨论"数据隐私与部署算力"这一工程约束。  
   https://arxiv.org/abs/2602.16181

## 5. 教辅提示

**可布置的小实验（2–4 学时）**
1. 运行 `theft_cnn_demo.py`，让学生先只看"准确率"一列排名，再看召回/AUC 排名，讨论两者为什么不一致；
2. 把 `theft_ratio` 从 0.09 改为 0.02 和 0.30，观察哑分类器准确率和类别加权的作用如何变化；
3. 让学生自己设计一个 3×3 卷积核加入字典 `K`（如"周末 vs 工作日"对比核），看 AUC 是否提升，并解释该核在电气上"测的是什么"；
4. 把阈值从 0.5 改成"只取嫌疑分数前 50 户"，计算命中数（即 precision@50），对接"稽查人力有限"的实际派单逻辑；
5. 本科 / 专升本延伸：下载 SGCC 数据，用 PyTorch 复现可训练的 2D CNN 或 Wide & Deep，对比本篇的手工卷积特征；再试随机欠采样集成（文献 1 思路）。

**常见坑**
- 只报准确率：不平衡数据上几乎必然虚高，至少同时报 AUC、召回、精确率；
- 先过采样再划分训练/测试集：合成样本"泄漏"进测试集，指标虚高——应先划分、只在训练集上过采样；
- 按时间混洗：同一户的前后时段分别进入训练和测试，或用未来数据训练、过去数据测试；
- 把"用量低"当成"窃电"：空置房、季节性用户、新装光伏的用户读数都可能骤降，需结合档案信息与现场核查，模型结果只是**嫌疑排序**，不能直接作为认定依据；
- 标签本身有噪声：公开数据中的"窃电"标签来自已查实案例，未被查到的窃电户被标为正常，模型上限受此限制。

**延伸阅读**
- 本仓 [`works/2026-11-06-seq2point-nilm`](../2026-11-06-seq2point-nilm/README.md)：同样基于电表数据的 CNN，可对比"回归电器功率"与"二分类窃电"的输入输出差异；
- 本仓 [`works/2026-11-16-iforest-pmu-anomaly`](../2026-11-16-iforest-pmu-anomaly/README.md)：无监督异常检测，可讨论"没有窃电标签时能否先用 Isolation Forest 圈出可疑户"。
