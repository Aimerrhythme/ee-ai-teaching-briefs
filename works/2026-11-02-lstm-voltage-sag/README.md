# 基于 LSTM 时序模型的配电网电压暂降故障预测

日期：2026-11-02  
slug：`lstm-voltage-sag`  
关键词：LSTM，电压暂降，故障预测

## 今日切入

主题队列下一条是用 LSTM 时序模型做配电网电压暂降（voltage sag / dip）相关的预测与识别。暂降是电能质量里出现频率最高的短时扰动之一：有效值在半周波到约一分钟内跌落到额定值的 10%–90%，敏感负荷（变频器、PLC、精密产线）可能跳机停产。教学上常见两条可落地的 AI 题面——**电压状态 / 残压的短时序列预测**，以及 **暂降类型（ABC 分类）或原因的端到端分类**——本篇做方法速览，方便在电能质量或配网仿真课上先跑通「波形 / RMS 窗 → LSTM → 预测或标签」的闭环。

## 背景 5 分钟

**电气问题。** 配网暂降多由短路故障、大电机启动、变压器投切或上游扰动引起。工程侧关注三件事：

- **特征量**：三相瞬时电压或半波 / 整周波 RMS、跌落深度、持续时间、相角跳变；标准讨论常引用 IEEE Std 1159 一类监测实践（RMS 跌至额定 10%–90%、持续约 0.5 周期–1 min）。
- **分类**：Bollen 的 ABC（A–G）七型按相量描述对称 / 不对称暂降；也有按原因（短路、电机、变压器）或按相对位置（上 / 下游）划分。
- **治理接口**：动态电压恢复器（DVR）、STATCOM、保护加速等。预测 / 识别模块给出「即将或正在发生什么」，补偿与保护仍由控制与整定负责——课堂不要把回归曲线直接写成「可投运预警系统」。

**AI 方法。** LSTM 用遗忘门、输入门、输出门维护细胞状态，适合暂降这种「平时平稳、事件段陡变」的短序列。常见接法有三类：

1. **状态预测**：以历史电压（可加电流、功率、频率）滑动窗回归下一时刻或短 horizon 的电压 / 残压，损失用 MSE / MAE。
2. **端到端分类**：直接吃三相原始波形或 RMS 序列，输出 NF / A–G 等标签，省去手工小波、S 变换特征。
3. **混合结构**：CNN 抽局部波形模式 + LSTM 建模时间依赖；可用 KECA 等非线性降维压冗余特征，再用元启发式调学习率、隐层单元、Dropout。

专科课堂上建议先做「合成波形 + 浅层 LSTM 分类 / 单变量电压预测」，再对照公开开源生成器与期刊里的 CNN-LSTM。

## 方法草图

**输入（课堂尺度）**

- **仿真 / 合成**：按 ABC 公式生成三相正弦，在指定时刻按严重度缩放幅值并可选相角偏移；采样例如 4 kHz、窗长约 0.1 s（约 410 点 × 3 相，与公开生成器设定同量级）；或在 IEEE 13 / 33 节点馈线上用 PSCAD、Simulink、OpenDSS 注入短路得实测风格波形。
- **监测风格特征**：滑窗 RMS、可选电流 / 有功 / 频率；归一化到额定有效值（例如把 0–100% 额定映射到 [0,1]）。
- **标签**：预测任务用下一时刻电压或残压；分类任务用 NF + A–G，或「正常 / 波动 / 暂降」粗标签。按时间切分训练 / 验证 / 测试，事件窗不要泄漏。

**模型或算法**

基线 A — **单变量 / 多变量 LSTM 电压预测**：输入层 → 1–2 层 LSTM → 全连接，Adam + MSE；报告 MAE、RMSE、\(R^2\)。  
基线 B — **端到端 LSTM 暂降分类**：输入 `(batch, T, 3)`，若干 LSTM（可前接 1D CNN）+ Softmax，损失用交叉熵；指标用准确率、宏平均 F1、混淆矩阵。  
进阶 — **KECA + CNN-LSTM**：先对多电气量做核熵成分分析降维，再 CNN-LSTM；超参可用改进 NGO 一类搜索（课堂可先网格搜学习率与单元数，不必复现整套元启发式）。

**输出与指标**

- 预测：MAE、RMSE、\(R^2\)；画出暂降段实测 vs 预测，检查突变沿是否滞后。
- 分类：总体 / 分类型准确率、MCC；对稀有类型（如 B、E、F、G）单独讨论样本不足。
- 对照：RMS 阈值法（跌破 0.9 pu 判暂降）、浅层 MLP、仅 CNN；合成集训 + 少量实测集测，观察域偏移。

课堂用离散草图（概念级，不是某一篇论文的训练脚本）：

```text
# A: voltage state prediction
v = normalize(rms_or_instantaneous_voltage)   # by nominal
for t:
    X = v[t-L+1:t]           # optional: current, power, frequency
    y = v[t+1]               # or residual voltage over short horizon
train LSTM(Adam, MSE); report MAE, RMSE, R2 on held-out sag windows

# B: end-to-end ABC classification
generate or load 3-phase windows shape (T, 3)   # e.g. T≈410
y_onehot in {NF, A, B, C, D, E, F, G}
model: [optional 1D-CNN] -> LSTM stack -> Dense Softmax
train on synthetic (balanced severities); test on measured dips
baselines: RMS threshold; MLP on hand features; same-arch without LSTM
```

## 最新公开信息

1. **LSTM 电压状态预测 + 新型趋近律滑模 DVR（开放获取，*Energies* 2024, 17(22), 5528，发表于 2024-11-05）。** Xue、Ma、Ma、Zhang、Bai（北华大学电气与信息工程学院等）用 LSTM（输入层–LSTM–全连接，Adam + MSE）对 10 kV A 相暂降电压状态做时序预测，文中报告 MAE = 0.1030、\(R^2\) = 0.9956；并设计新型趋近律滑模控制的 DVR，在 20% 对称暂降等仿真中对比 PI 与经典滑模。适合把「预测模块」和「补偿控制」分开讲：前者是数据拟合，后者仍要稳定性论证。

   https://doi.org/10.3390/en17225528

2. **端到端 LSTM 暂降 ABC 分类与开源合成数据生成器（开放获取，*Energies* 2022, 15(8), 2898，发表于 2022-04-15）。** Turović、Dragan 等（诺维萨德大学）用可配置 Python 生成器按 ABC 公式合成数十万条三相波形，训练多层 LSTM / CNN-LSTM；最佳模型在 Bollen 实测集上的窗级准确率约 92.68%（sterile 训练集、instance / window 指标见原文表 5）。生成器、模型与权重开源：https://bitbucket.org/sara_e21/ee2021-mdpi-vsc/ 。课堂可先复现「合成训练 → 实测抽检」，体会标签平衡与域偏移。  
   https://www.mdpi.com/1996-1073/15/8/2898  
   https://doi.org/10.3390/en15082898

3. **KECA + SCNGO 优化的 CNN-LSTM 暂降相关电压预测（开放获取，*Energies* 2026, 19(2), 428，发表于 2026-01-15）。** Sun、Xu、Bai（北华大学）对电压、电流、功率、频率做 KECA 降维，再用改进北方苍鹰优化（SCNGO）整定 CNN-LSTM 的隐层单元、学习率与 Dropout；在疫苗冷柜交流监测数据（约 2 万条波动样本、10 ms 采样）上，文中表 5 给出 SCNGO-CNN-LSTM 的 MSE ≈ 150.24、RMSE ≈ 13.41、MAE ≈ 1.83、\(R^2\) ≈ 98.81%，相对未优化 CNN-LSTM 的 MSE / MAE 有明显下降（原文亦给出相对 NGO / GWO 变体的降幅百分比）。单样本推理时间约 3 ms 量级。对象是设备侧监测序列，不是整条馈线故障定位，引用时勿外推。

## 教辅提示

**小实验。** 建议三步，由易到难。

1. **阈值基线。** 对公开或自仿真三相电压算滑窗 RMS，低于 0.9 pu 判暂降；统计检出延迟与漏检。
2. **合成分类。** 用上述开源生成器（或自写 ABC 公式）生成平衡的 A–G + NF，训练浅层 LSTM；固定随机种子，画混淆矩阵。
3. **预测对照。** 在同一暂降段上比较：持续法、单层 LSTM、可选 CNN-LSTM；只改网络、不改窗长与归一化，报告 MAE / \(R^2\)，并目视检查跌落沿。

**常见坑**

- 把「分类准确率」写成「故障预测准确率」——任务是类型识别还是未来残压回归，标题和指标必须一致。
- 合成边沿过于方波、无噪声，迁到实测波形准确率塌方；生成器里的平滑与幅值抖动参数要打开再对比。
- 稀有类型样本极少却报总体准确率；应对每类单独列表，或合并粗标签。
- 用含测试事件的全局均值方差做标准化，或打乱时间造成泄漏。
- 把文献 MAE = 0.1030 或 92.68% 抄成课程验收线；对象、单位与划分都不同。
- 预测曲线好看就宣称可替代保护或 DVR 投运判据——缺少整定、通信与误报代价讨论。

**延伸阅读。** 先读 *Energies* 2024 一文第 4 节 LSTM 预测流程与指标，建立「电压状态回归」直觉；再读 *Energies* 2022 一文第 4 节生成器参数与第 5 节实测迁移结果，做开源小实验；进阶再看 *Energies* 2026 一文 KECA 特征表与 CNN-LSTM 超参表。标准语境可对照 IEEE Std 1159 对 sag/dip 持续时间与幅值区间的表述（以标准文本为准）。
