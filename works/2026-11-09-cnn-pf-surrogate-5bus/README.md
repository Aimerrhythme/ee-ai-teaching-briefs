## 今日切入

主题池下一条是「用神经网络近似潮流计算」：先用牛顿—拉夫逊（NR）潮流在一个 5 母线小系统上跑几千次蒙特卡洛负荷场景，把算出的母线电压和支路潮流当标签，再训练一个一维 CNN 直接从负荷向量「一步」吐出结果。今天值得写，是因为 2026 年 9—10 月 arXiv 上接连出现了几篇潮流代理模型的工作：一篇在统一实验框架下比较多种图神经网络（GNN）与 MLP 基线，一篇用同一个异构 GNN 同时做潮流、最优潮流和状态估计，还有一篇专门处理 N-1 / N-2 拓扑变化下的概率潮流。它们共同给课堂带来一个好用的反面教材：**不看拓扑的「平铺向量」网络在小系统上还凑合，系统一大、拓扑一变就会露馅**。本篇按「为什么要代理 → 5 母线怎么造数据 → CNN 草图 → 怎么诚实地评价」做方法速览。

## 背景 5 分钟

**电气问题。** 潮流计算给定各母线的注入功率（PQ 母线给 \(P,Q\)，PV 母线给 \(P,|V|\)，平衡母线给 \(|V|,\delta\)），求全网电压幅值与相角，再推出支路功率和损耗。核心方程是节点功率平衡：

\[
P_i = \sum_{j=1}^{n} |V_i||V_j|\left(G_{ij}\cos\delta_{ij} + B_{ij}\sin\delta_{ij}\right),\quad
Q_i = \sum_{j=1}^{n} |V_i||V_j|\left(G_{ij}\sin\delta_{ij} - B_{ij}\cos\delta_{ij}\right)
\]

这是非线性方程组，NR 法每次迭代都要形成并分解雅可比矩阵。单次在 5 母线上快得可以忽略，但规划里的蒙特卡洛 / 概率潮流、N-1 扫描、实时安全校核动辄要算成千上万次，计算量就成了瓶颈。这正是「代理模型（surrogate）」的动机：**先花时间用精确求解器造数据，再训练一个推理很快的近似函数**。

**AI 方法。** 代理模型就是学一个映射 \(f_\theta:\ \text{注入功率} \mapsto (|V|,\delta,\ \text{支路潮流})\)。教学上有三档：

1. **MLP（全连接）**：把各母线负荷拼成一个向量直接回归，最简单，但完全不知道哪两条母线相连。
2. **一维 CNN**：把按母线编号排好的负荷向量当作「一维信号」做卷积。卷积核只看相邻编号，**编号相邻不等于电气相邻**，所以它的「局部性」是人为的；5 母线上它能工作，正好用来讨论这一点。
3. **GNN（图神经网络）**：以母线为节点、线路为边，沿真实拓扑传递信息，还能把线路阻抗作为边特征。这是近两年的主流，也是下面三条新文献的共同方向。

课堂主线建议：**用 CNN 跑通「造数据—训练—对照」全流程，再用 GNN 文献解释 CNN 为什么只是教学起点。**

## 方法草图

**输入（课堂尺度）**

- **系统**：pandapower 自带的 5 母线算例 `pandapower.networks.case5()`，文档注明来自 F. Li 与 R. Bo 的《Small Test Systems for Power System Economic Studies》，数据源自 MATPOWER。母线少、手算可核对，适合专科课。
- **造数据**：对每个负荷的 \(P,Q\) 按名义值做均匀扰动（例如 ±30% 起步，进阶再放宽到 ±80%，与下文基准论文的设定量级一致），每个样本调用一次 `pp.runpp(net)`；**不收敛的样本丢弃并计数**，这个计数本身就是一条可讨论的数据。
- **特征**：各母线 \(P_d, Q_d\)（按母线编号排成 2 通道 × 5 长度的张量）；PV 母线的出力和电压设定若也扰动，则作为额外通道。
- **标签**：PQ 母线 \(|V|\)、非平衡母线 \(\delta\)，可选各支路有功潮流 \(P_{ij}\) 与负载率。
- **划分**：训练 / 验证 / 测试 = 70/15/15；**均值方差只在训练集上估计**。

**模型或算法**

基线 A — **直流潮流（DC PF）**：线性近似，零训练成本，作为「物理捷径」对照。  
基线 B — **MLP**：两三层全连接，参数量与 CNN 对齐。  
模型 — **1D CNN**：两三层 `Conv1d`（核长 3、same padding）+ 全连接输出；输出多个量时各自标准化后再算 MSE。  
扩展（只讲概念）— **GNN**：把 `net.line` 的连接关系和 \(R,X\) 做成边，消息传递 2—3 层，再加一个全局池化向量（见下文文献 1、2 的消融结论）。

**输出与指标**

- **电压幅值 MAE（p.u.）** 与 **相角 MAE（度）**，分开报，两者难度差很多。
- **最大绝对误差**：安全校核关心最坏情况，平均值好看不代表能用。
- **功率失配（KCL 残差）**：用预测的 \(|V|,\delta\) 代回上面的功率方程，算各母线 \(\Delta P,\Delta Q\)。这一步把「统计上准」和「物理上自洽」分开。
- **速度**：同一批测试样本，NR 逐个求解总耗时 vs 代理模型批量推理耗时（注意 5 母线上 NR 本身就很快，加速比不会夸张，这是要诚实告诉学生的）。

课堂用草图（概念级，不是某一仓库的训练脚本）：

```text
import pandapower as pp, pandapower.networks as pn
net0 = pn.case5()

X, Y, failed = [], [], 0
for k in range(N):                      # 例如 N = 3000
    net = copy(net0)
    net.load.p_mw   *= U(0.7, 1.3, size=n_load)
    net.load.q_mvar *= U(0.7, 1.3, size=n_load)
    try: pp.runpp(net)                  # 牛顿-拉夫逊
    except LoadflowNotConverged: failed += 1; continue
    X.append(bus_injections(net))       # 形状 [2, 5]
    Y.append(concat(net.res_bus.vm_pu, net.res_bus.va_degree, net.res_line.p_from_mw))

scale on train only
cnn = Conv1d(2,16,3) -> ReLU -> Conv1d(16,16,3) -> ReLU -> Flatten -> Dense(len(Y))
fit(cnn, X_train, Y_train, loss=MSE)

report MAE_vm_pu, MAE_va_deg, MaxAE, mean|ΔP|,|ΔQ| (代回功率方程), 推理耗时 vs runpp
compare with: DC PF, MLP
```

## 最新公开信息

1. **GNN 潮流基准：Clerici、Bohigas-Daranas、Latif-Martínez、Prieto-Araujo、Gomis-Bellmunt、Barlet-Ros（UPC），arXiv:2610.38985（2026）。** 在 IEEE 14 / 118 母线上，用 pandapower 各生成 2000 个可行样本（负荷 ±80%、线路阻抗 ±5%，不收敛样本丢弃），在约 10 万参数的统一预算下比较 GCN、GraphSAGE、GINE、GAT、ResGated、Graph Transformer 与 MLP 基线。几个直接可搬进课堂的结论：（a）**MLP 基线在 118 母线上基本失效**，PQ 母线相角的阈值相对误差（TRMAE）在约 217%—293% 之间，而各 GNN 多在 10%—25%；在 14 母线上 MLP 约 16%，GNN 约 1%，说明小系统会掩盖「不看拓扑」的问题。（b）作者把**功率失配（KCL-MAE）**而不是统计误差当作选模型的决定性指标，并指出两者并不总是一致。（c）消融显示去掉线路阻抗边特征或去掉全局池化都会明显变差，相角误差随离平衡母线的跳数增加而上升。  
   https://arxiv.org/abs/2610.38985

2. **一个模型同时做潮流、最优潮流、状态估计：Bohigas-Daranas 等（UPC），arXiv:2609.16738（2026-09 提交）。** 用异构 ResGated 图卷积网络（按平衡 / PV / PQ 母线分类型编码，边特征为 \(R,X,B\)），在 IEEE 14 / 118 母线上联合训练三类任务；数据用 pandapower 与 VeraGrid 生成。文中明确把早期 MLP 和 CNN 列为局限：MLP 不利用拓扑，CNN 只适合规则的欧氏网格数据。118 母线中等负荷场景下平均 NRMSE 约 0.0031；在训练中没见过的高负荷加拓扑变化场景（high-topo）上升到约 0.063，可用来讲「分布外」到底掉多少。  
   https://arxiv.org/abs/2609.16738

3. **拓扑变化下的概率潮流：arXiv:2610.13495（2026-10 提交，TDD–HBGNN）。** 指出绑定固定母线—支路图的代理模型在线路停运改变耦合关系后泛化很差；方法上先用灵敏度线性先验给出一阶电压 / 相角响应，再让分层 GNN 学非线性残差。在 IEEE 118 与波兰 2746 母线系统的 N-1 / N-2 未见拓扑上，全网相角误差比六种基线低约 2.47—4.20 倍，模型约 0.658M 参数，单个概率场景前向时延约 0.161—1.793 ms。课堂启示：「线性先验 + 学残差」和本篇的「DC 潮流基线」是同一思路的升级版。  
   https://arxiv.org/abs/2610.13495

## 教辅提示

**小实验（由易到难）**

1. **手算对照。** 先用 `pp.runpp` 跑名义工况，让学生对照节点导纳矩阵手算一次功率平衡，确认标签是怎么来的。
2. **造数据并数失败。** 把扰动幅度从 ±10% 逐步放到 ±80%，记录不收敛比例和电压越限比例，讨论「代理模型只能在见过的工况里可信」。
3. **DC vs MLP vs CNN。** 同一测试集比较 \(|V|\) 与 \(\delta\) 的 MAE、最大误差和功率失配；把母线编号随机打乱后重训 CNN，看结果变不变，借此说明「编号相邻不等于电气相邻」。
4. **速度账。** 测 1000 个样本的 NR 总耗时和 CNN 批量推理耗时，再讨论：5 母线上加速比意义不大，换成 118 母线或要跑几万个场景时才有意义。
5. **进阶讨论。** （a）测试时断开一条线路（N-1），不重训直接预测，观察误差暴涨；（b）阅读文献 1 的 Table 8 / 9，说出 MLP 与 GNN 的差距在 14 母线和 118 母线上为什么不同；（c）把 CNN 改成「DC 潮流结果 + 网络学残差」，看误差能否下降。

**常见坑**

- 只报平均误差：相角和幅值量纲、难度不同，要分开报，并补最大误差。
- 统计误差小就宣称「可以替代潮流」：必须把预测代回功率方程看失配，文献 1 正是把它当决定性指标。
- 归一化统计量用了全量数据，造成信息泄漏。
- 训练和测试都是同一拓扑同一负荷范围，却声称能用于故障或检修方式。
- 不收敛样本悄悄丢掉不报告，导致数据分布偏向「好算」的工况。
- 把不同论文里的 NRMSE、TRMAE、MAE 横向比较谁更先进，它们的系统、指标和数据设定都不同。

**延伸阅读。** 先读文献 1 的第 4 节（数据生成与指标定义）和第 5.3 节消融表；再读文献 2 第 II 节，它把潮流、最优潮流、状态估计的数学关系讲得很清楚，适合当课前复习。想往概率潮流和拓扑变化方向走，读文献 3 的摘要与方法概述即可。
