# 锂电健康状态 CNN+随机森林估算

日期：2026-11-05  
slug：`cnn-rf-battery-soh`  
关键词：SOH，CNN，随机森林，储能

## 今日切入

主题池下一条是锂电池健康状态（SOH）估算：只拿到一段不完整的充放电曲线，先用卷积神经网络（CNN）从曲线里抽出与老化有关的指标，再用随机森林把这些指标融合成最终的 SOH 估计。今天值得写，是因为 2026 年 8 月一篇新预印本又一次证明「**只用局部放电片段也能估 SOH**」，而且它同样拿随机森林来挑特征。把 2020 年的 CNN+RF 原型和这篇新工作放在一起，正好讲清一件事：**真实储能和电动汽车里几乎拿不到完整曲线，方法设计要从“数据缺一截”出发**。本篇按「概念 → 数据 → 两步模型 → 诚实评估」做方法速览。

## 背景 5 分钟

**电气问题。** 储能电站和电动汽车的电池管理系统（BMS）需要知道每个电芯“还剩多少本事”。教学上最常用的定义是容量型 SOH：

$$
\mathrm{SOH} = \frac{Q_\text{当前最大可用容量}}{Q_\text{额定容量}} \times 100\%
$$

通常把 SOH 降到 80% 视为寿命终止（EoL）。最直接的测法是满充后完全放电、用库仑计数积分电流，但实际运行中电池很少从 100% 放到 0%，频繁满充满放还会加速老化。所以现实问题变成：**只看到一段部分充电或部分放电曲线（例如 SOC 20%→70%），怎么估 SOH？** 要先让学生分清：

- **SOC（荷电状态）** 是“油箱里还剩多少”，**SOH** 是“油箱本身变小了多少”，两者常被混淆。
- **DoD（放电深度）**：1 − SOC。部分放电就是 DoD 只覆盖一个区间。
- **增量容量分析（ICA）**：对电压–容量曲线求 \(dQ/dV\)，峰谷位置和高度随老化移动，是经典的人工健康指标；缺点是要先平滑、求导放大噪声，而且峰谷常落在高/低 SOC 区，部分放电时可能整段看不见。

**AI 方法。** 两步法可以看成“自动特征工程 + 稳健回归”：

1. **一维 CNN**：卷积核在电压序列上滑动，抽取局部形状（相当于自动找“拐点、平台、斜率变化”）；池化层让特征对位置平移不那么敏感，正好应对每次截取的 SOC 区间不同。
2. **随机森林回归**：由很多棵决策树投票平均，对彼此高度相关的输入（多重共线性）不敏感，还能给出特征重要度，便于解释“哪个指标在起作用”。

## 方法草图

**输入（课堂尺度）**

- **数据**：Severson 等（*Nature Energy* 2019）公开的 124 节 A123 磷酸铁锂/石墨 18650 电芯快充老化数据，额定 1.1 Ah，电压 2.0–3.6 V，30 ℃ 恒温，4C 恒流放电。也可用西安交大 XJTU 电池数据（见下方 SOHbenchmark）。
- **造“部分曲线”**：从每圈完整放电曲线上随机截取一段，比如起始 DoD 约 0.2、截取约 50% 额定容量，得到一段电压–容量序列；重采样到固定长度（如 100 点）。
- **标签**：每圈的 SOH（该圈最大放电容量 / 额定容量）。
- **划分**：**按电芯划分**训练 / 验证 / 测试（同一节电池的所有循环只出现在一个集合里），否则相邻循环高度相似，测试集等于提前见过。

**模型或算法**

基线 A — **线性回归 / 随机森林 + 手工特征**：段内电压均值、方差、曲线斜率、IC 峰面积等十来个统计量。  
基线 B — **ICA + 随机森林**：只用 IC 曲线最低谷值当指标。  
模型 1 — **SOH-CNN**：输入本圈部分曲线，直接输出 SOH。  
模型 2 — **ΔSOH-CNN**：输入本圈和上一圈两条曲线（两个通道），输出相邻两圈的 SOH 差值，再累加 \(\mathrm{SOH}_t = \mathrm{SOH}_{t-1} + \Delta\mathrm{SOH}_t\)。  
模型 3 — **RF-CNN**：把模型 1、2 的输出当作两个指标，交给随机森林回归出最终 SOH。

**输出与指标**

- **MAE / RMSE**（以 SOH 百分点计），同时报 **MAPE**。
- **逐电芯 SOH 轨迹图**：真值与估计叠画，看相邻循环是否“锯齿乱跳”（一致性）。
- **截取区间敏感性**：把截取段从宽（DoD 0.1–0.8）逐步缩到窄（0.4–0.5），画误差随区间变窄的上升曲线。
- **特征重要度**：随机森林给出两路 CNN 指标各自的贡献比。

课堂用草图（概念级，不是某一篇论文的训练脚本）：

```text
cells = load_severson()                          # each cell: list of cycles
train_cells, val_cells, test_cells = split_by_cell(cells, 0.6, 0.2, 0.2)

for each cycle c:
    seg   = random_partial_discharge(c.V, c.Q, dod_start~N(0.2,0.03), width~U(0.45,0.55))
    x_t   = resample(seg.V, 100)                 # present segment
    x_tm1 = resample(prev_cycle_segment.V, 100)  # previous cycle
    y     = c.capacity / 1.1

scaler fitted on train_cells only

cnn_a = CNN1D(in_ch=1) ; fit(cnn_a, x_t -> y)                  # SOH-CNN
cnn_b = CNN1D(in_ch=2) ; fit(cnn_b, [x_t, x_tm1] -> dy)        # ΔSOH-CNN
z = [cnn_a(x_t), accumulate(cnn_b)]                            # two indicators
rf = RandomForestRegressor(n_trees=200) ; fit(rf, z -> y)      # RF-CNN

report per model: MAE, RMSE, MAPE on test_cells; SOH trajectories; rf.feature_importance
repeat for narrower windows: DoD 0.1-0.8, 0.2-0.7, 0.3-0.6, 0.4-0.5
```

## 最新公开信息

1. **本主题的原型：Yang、Song、Hofmann、Sun（密歇根大学），arXiv:2010.10452（2020 年 10 月提交），正式版发表于 *Journal of Energy Storage* 48 (2022) 103857。** 用 Severson 数据的 4C 放电曲线人为截取部分放电，对比 ICA+随机森林、SOH-CNN、ΔSOH-CNN 和 RF-CNN。CNN 为十层结构，卷积核长 3、50 个滤波器、池化 3；数据按 60/20/20 划分并做五折交叉验证。在 DoD 约 0.2–0.7 的条件下，平均 MAE 分别为 SOH-CNN 1.28%、ΔSOH-CNN 1.57%、RF-CNN 0.85%；含低 DoD 区的条件下 ICA+随机森林 2.31%、RF-CNN 0.72%。表 II 显示截取区间从 DoD 0.1–0.8 缩到 0.4–0.5 时，RF-CNN 的 MAE 从 0.62% 升到 1.51%，SOH-CNN 从 0.99% 升到 2.92%。随机森林给出的两路 CNN 指标重要度之比在五折中为 1.00–1.87，说明两路都有贡献。值得课堂注意的细节：论文的 MAE 公式是按真值归一化的相对误差，严格说更接近 MAPE；预印本没写明五折是按电芯还是按循环划分；作者自己也承认只在单一 4C 放电、30 ℃ 条件下验证。CNN 用 PyTorch，随机森林用 MATLAB 统计与机器学习工具箱，正好适合 Python 与 Matlab 双线教学。  
   https://arxiv.org/abs/2010.10452

2. **任意局部放电片段估 SOH：Ispizua、Gil-López、Arrizabalaga、Laña（Tecnalia 等），arXiv:2608.14764（2026 年 8 月编号）。** 同样用 Severson 数据（文中写 122 节，留 10 节专作验证），把放电曲线按电压均分成 8 段、每段对应 5% 额定容量；每段提取 15 个候选特征（电压–容量曲线弧长、斜率、面积，电压电流的均值方差峰度偏度，IC 曲线面积、最大值等），**用随机森林特征重要度筛选**（重要度高于 1/15 才保留），再为每段训练一个嵌入 Verhulst 退化方程的物理信息神经网络（PINN），并用 XGBoost 分类器自动判断新片段属于哪一段（验证准确率 0.99）。表 4 中 8 段的 PINN MAPE 均低于 4%，最好的是第 6 段（约 3.14 V 附近，只保留了曲线斜率一个特征），MAPE 1.543%、\(R^2\) 0.952；对照的普通前馈网络各段都更差。另一个可讨论的结论：在他们的膝点 / 寿命预测对比中，放电数据比充电数据更有信息量。注意文中把 SOH 定义为放电曲线拐点处的容量，不是常规的最大容量比；正文写第 6 段 MAPE 为 1.52%，表 4 为 1.543%，第 8 段也有类似小差异，论文未解释。  
   https://arxiv.org/abs/2608.14764

3. **开源教学工具：SOHbenchmark（Wang Fujin 等，西安交大），对应论文 *Journal of Energy Storage* 77 (2024) 109884。** 仓库提供 XJTU 与 MIT 两套共 100 节电池的预处理数据，内置 CNN、LSTM、GRU、MLP、Attention 五种模型，输入可选完整充电、**部分充电**或手工特征，归一化可选 min-max 或标准化，一条命令就能按电池编号留出测试。课堂可直接拿它的 CNN + `partial_charge` 当“第一步特征抽取”，再自己接 scikit-learn 随机森林。仓库最近一次推送是 2023 年 12 月，GitHub 上约 211 星，未声明许可证，课堂使用前请查看仓库说明。  
   https://github.com/wang-fujin/SOHbenchmark  
   https://doi.org/10.1016/j.est.2023.109884

## 教辅提示

**小实验（由易到难）**

1. **先算真值。** 用 Severson 或 XJTU 数据，对一节电池画「循环数–SOH」曲线，标出 80% 寿命线和容量“膝点”，让学生先理解标签从哪来。
2. **手工特征 + 随机森林。** 截取 DoD 0.2–0.7 的部分放电段，算 8–10 个统计特征，训练随机森林，输出特征重要度柱状图。讨论：重要度最高的是斜率还是 IC 峰？和电化学直觉吻合吗？
3. **CNN 抽特征再接随机森林。** 训练一维 CNN 直接回归 SOH，取其输出（或倒数第二层向量）作为随机森林输入，与第 2 步对比 MAE。
4. **截取区间扫描。** 把截取宽度从 70% 缩到 10%，画三条“误差–区间宽度”曲线（手工特征 RF / CNN / CNN+RF），联系第 1 条论文的表 II。
5. **进阶：充电段 vs 放电段。** 同样宽度下分别用部分充电段和部分放电段训练，检验第 2 条预印本“放电更有信息量”的结论在你的设置里是否成立。

**常见坑**

- 按循环随机划分训练 / 测试：同一节电池的相邻循环几乎一样，误差会被严重低估，必须按电芯划分。
- 把 SOC 和 SOH 混为一谈，或者用“剩余电量百分比”当 SOH 标签。
- 归一化统计量用了全体数据（含测试电芯）。
- 只看平均 MAE，不画逐电芯轨迹：相邻循环估计值上下乱跳，在 BMS 里是不可用的。
- 只在 Severson 一套磷酸铁锂数据上训练，就声称适用于三元锂（NCM）或其他倍率、温度。
- 把论文里的 “MAE” 和自己算的绝对误差直接比较，先确认对方是否按真值做了归一化。
- 不同论文的 SOH 定义不同（最大容量比 vs 拐点容量），数字不能直接横向对比。
