# 配电网状态估计 GNN 入门（2026-11-20）

> 主题：`gnn-grid-state-estimation` · 关键词：GNN、状态估计、图结构、量测  
> 定位：教辅 / 技术速览，供课堂与课题讨论参考；不是毕业论文代写。

## 1. 今日切入

**一句话**：把配电网的母线当"节点"、线路当"边"，让图神经网络（GNN）沿着拓扑"传话"，用少量电压表 + 大量不准的伪量测去估计每条母线的电压——再和经典的加权最小二乘（WLS）放在同一张表里比。

**为何今天写**：前面几篇处理的都是"一条时间序列"（负荷、充电、PMU 流），而状态估计的数据天生是**一张图**：一个母线的电压由它上游走过的线路和下游挂的负荷共同决定。本篇是本仓第一篇显式使用图结构的作品，正好把 11-09 的潮流代理模型（`cnn-pf-surrogate-5bus`）和 11-16 的 PMU 异常检测（`iforest-pmu-anomaly`）串起来：前者告诉学生"潮流可以被数据近似"，后者告诉学生"量测会出错"，状态估计恰好就是"在有错的量测上反推潮流状态"。

## 2. 背景 5 分钟

**电气问题**：状态估计（SE）的目标是根据调度/配电自动化系统采集到的量测（电压、功率、电流），估出全网各母线的电压幅值和相角——它们是潮流计算、电压控制、故障分析的"起点"。输电网量测冗余度高，经典做法是 WLS + 高斯-牛顿迭代；配电网则麻烦得多：**量测稀疏**（往往只有变电站出口和少数配变终端有表）、线路 R/X 比大、三相不平衡、分布式光伏让潮流双向流动。量测不够时只能用"伪量测"（按典型负荷曲线或用户电量推算的注入功率）补足可观测性，而伪量测误差常有 20%–50%。pandapower 文档给出的经验是：n 个母线至少需要 2n−k 个量测（k 为平衡节点数）才能求解，实用中希望约 4n 个——配电网通常远达不到。

**AI 方法**：GNN 的核心是**消息传递**：每一层，节点把自己和邻居的特征加权汇总，得到新特征；堆 K 层，就能"看到"K 跳以内的信息。这和电气直觉一致：一条没装表的母线，最有用的信息来自电气上相邻的有表母线和沿线负荷。训练方式通常是**有监督代理**：用潮流仿真批量生成"量测 → 真实状态"样本，训练 GNN 直接输出电压；推理时只需一次前向计算，不迭代、不求逆矩阵。代价是：它学的是训练分布，拓扑一变、量测位置一变，就要讨论泛化问题。

## 3. 方法草图

**输入（每个节点一组特征）**
- 电压量测值（无表则填 0）+ "是否有表"掩码；
- 伪量测注入功率 p、q（典型值，误差大）；
- 静态特征：到变电站的电气距离（路径电阻之和）等。
- 边：线路连接关系，可附 r、x 作为边特征。

**模型**
- 课堂最简版：**SGC（简化图卷积）**——先用归一化邻接矩阵把特征传播 K 次 `H = Â^K X`，再用一个所有节点共享的线性回归输出电压，训练可用闭式岭回归，**纯 numpy 即可跑通**；
- 进阶版：GCN / GAT（图注意力）多层非线性网络，用 PyTorch Geometric 实现；文献里还有在"因子图"上做消息传递、把量测本身也当节点的做法（见第 4 节文献 1）。

**输出与指标**
- 各母线电压幅值（pu），可扩展到相角；
- 指标：**未装表母线**上的 RMSE / 最大绝对误差（单位 10⁻³ pu 更直观）；推理耗时；量测缺失、拓扑切换时的误差变化。

**本目录附带的合成数据演示**：[`sgc_dsse_demo.py`](./sgc_dsse_demo.py)（仅依赖 numpy，约 1 秒跑完）  
12 母线辐射状馈线，用 LinDistFlow 线性化生成"真值"，只在 3 个母线（含变电站）装电压表（噪声 0.2%），其余用相对误差 30% 的伪量测。对比 WLS 与不同传播跳数 K 的 SGC。本机（2026-11-20）运行输出：

| 方法（500 个测试样本，9 个未装表母线） | RMSE（10⁻³ pu） |
|---|---|
| WLS（已知线路参数的线性化模型 + 伪量测） | 1.938 |
| 逐节点岭回归（K=0，不用图） | 2.631 |
| SGC，K=1 | 2.360 |
| SGC，K=2 | 1.991 |
| SGC，K=3 | 1.852 |

读法：K 从 0 增到 3，误差单调下降——"让信息沿拓扑多走几跳"确实有用；K=3 的纯数据模型与"知道全部线路参数"的 WLS 处于同一水平。注意这是**线性化、无拓扑变化、训练/测试同分布**的玩具设定，数字只用于课堂对比趋势，不代表真实配电网上的性能。

## 4. 最新公开信息

1. **State Estimation in Electric Power Systems Leveraging Graph Neural Networks**（Ognjen Kundacina, Mirsad Cosovic, Dejan Vukobratovic；arXiv:2201.04056）  
   较早把 GNN 用于电力系统状态估计的工作之一：以 PMU 电压、电流量测为输入，用"随机抽取量测组合 + 线性 SE（PMU）求解器打标签"的合成数据集训练 GNN，目标是推理阶段快速且准确地给出母线复电压估计，并测试了输入数据缺失时预测的敏感性。场景偏输电网/PMU，但"用传统求解器结果做标签、GNN 做快速代理"的思路正是本篇课堂实验的原型。同组后续的 arXiv:2207.11465 把方法推广到含 SCADA 传统量测的非线性 SE（增广因子图），可作延伸阅读。  
   https://arxiv.org/abs/2201.04056

2. **Robust and Interpretable Graph Neural Networks for Power Systems State Estimation**（Arbel Yaniv, Kilian Golinski, Christoph Goebel；arXiv:2603.23357，2026-03 提交，正文标注投稿 PSCC 2026）  
   聚焦**配电系统**状态估计（DSSE）：在多个 SimBench 电网、含拓扑变化与不同量测渗透率的场景下，对比可解释的图神经加性网络（GNAN）、带边条件的消息传递机制与标准图注意力网络（GAT）。摘要结论：GNAN 精度落后于 GAT，但配合作者提出的边注意力机制可作为分析"图学习到底学到了什么"的探针；是否引入远处节点的信息能改善学习，取决于电网拓扑和可用数据。——这与本篇演示"K 跳数怎么选"的问题直接对应。  
   https://arxiv.org/abs/2603.23357

3. **Learning a Generalized Model for Substation Level Voltage Estimation in Distribution Networks**（Muhy Eddin Za'ter, Bri-Mathias Hodge；arXiv:2510.16063）  
   提出分层 GNN 做变电站级电压估计，结合电气拓扑与物理特征，在公开的 SMART-DS 数据集上覆盖多个变电站、数千母线和不同 DER 渗透率场景训练评估。摘要称：RMSE 比其他数据驱动模型最多低约 2 倍，在仅 1% 量测覆盖率下仍保持较高精度；作者表示会开源模型、数据生成流程和微调脚本。适合给专升本/本科学生展示"从 12 母线玩具到数千母线真实规模"之间差的是什么。  
   https://arxiv.org/abs/2510.16063

## 5. 教辅提示

**可布置的小实验（2–4 学时）**
1. 运行 `sgc_dsse_demo.py`，让学生画出"K vs RMSE"曲线，并解释为什么 K=0 最差；再试 K=4、5，看是否继续变好（对照文献 2 关于远距离信息的讨论）；
2. 改 `meter` 列表：把电压表从 3 个减到 2 个、或挪到馈线末端，观察 WLS 与 SGC 谁更敏感——引出"量测配置/可观测性"；
3. 把伪量测误差 `sig_pseudo` 从 0.30 调到 0.10 和 0.50，体会伪量测质量对两种方法的影响；
4. 本科延伸：用 pandapower 的 `estimate()`（支持 WLS、LAV 等估计器）在其自带配电算例上生成真实非线性 SE 标签，再用 PyTorch Geometric 训练 2 层 GCN 替换 SGC；
5. 专升本延伸：训练时用一种开关状态，测试时断开一条支路改成另一种辐射拓扑，比较误差——体会"拓扑变化下的泛化"为何是文献 2、3 都在处理的难点。

**常见坑**
- 只在**有表母线**上算误差：那里本来就有量测，误差天然小，要单独报告未装表母线；
- 训练和测试用同一批伪量测噪声或同一天的负荷，结果虚高；
- 把 GNN 当成 WLS 的"替代品"而非"加速器/补充"：WLS 有坏数据检测（残差检验）和可观测性分析等成熟工具，GNN 输出没有天然的置信度；
- 层数（K）越多不一定越好：过深会出现过平滑，所有节点特征趋同；
- 忽略标签来源：如果标签本身来自 WLS 估计结果而非真实潮流，GNN 学到的上限就是 WLS。
