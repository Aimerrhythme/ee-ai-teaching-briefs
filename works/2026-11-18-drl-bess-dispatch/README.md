# 分时电价下储能 DQN 调度沙盒（2026-11-18）

> 主题：`drl-bess-dispatch` · 关键词：储能、DQN、强化学习、分时电价  
> 定位：教辅 / 技术速览，供课堂与课题讨论参考；不是毕业论文代写。

## 1. 今日切入

**一句话**：一台储能、一条 24 小时负荷、一张峰谷电价表，每小时只能选「放电 / 待机 / 充电」三个动作之一——把它写成强化学习环境，让一个两层隐层的 DQN 自己学会"低谷充、高峰放"，再和"不装储能""无脑充满放空"两条基线比一天的电费。这是讲清**状态—动作—奖励**最省事的电气案例。

**为何今天写**：昨天的 PINN 篇用到的 IEEE 课程开源笔记本里，紧挨着就有一个 `05_DRL_BESS` 储能 DQN 示例（MIT 许可，笔记本 CPU / Colab 可跑），可以直接拿来当课堂底稿；同时 2026 年 9 月 arXiv 上有一篇用真实商业光储全年数据对比 MILP / MPC / 深度强化学习的预印本，结论是"所评估的 RL 配置不如简单的持续性预测 MPC"。一个"能跑通的玩具" + 一个"真实数据泼冷水"，正好组成一节既有兴趣又不夸大的课。

## 2. 背景 5 分钟

**电气问题**：用户侧储能在分时电价（TOU）下的核心收益来自**峰谷价差套利**：谷时（如夜间）从电网充电，峰时放电供本地负荷，减少高价时段购电量。约束包括：储能容量（kWh）、充放电功率上限（kW）、充放电效率、SOC 上下限，以及"一天结束时 SOC 要回到某个水平"（否则今天看起来省钱，其实是透支了明天）。经典做法是在已知负荷与电价时写成线性规划 / 混合整数线性规划（LP/MILP）求最优；实际运行中负荷和价格要预测，常用模型预测控制（MPC）滚动求解。

**AI 方法**：强化学习不先写优化模型，而是让智能体在环境里试错：每一步观察**状态** s（时刻、电价、负荷、SOC），选**动作** a，拿到**奖励** r（负的电费 + 惩罚项），目标是最大化一整天的累计奖励。DQN（Deep Q-Network）用神经网络近似动作价值 Q(s, a)，输出"在这个状态下选每个动作的长期价值"，选最大的那个。训练时靠两项标准技巧稳定：**经验回放**（从历史转移样本里随机抽小批量）和**目标网络**（Bellman 目标用一个慢更新的副本计算）。动作是离散的三档，正好适合 DQN。

## 3. 方法草图

**环境（以课程笔记本为例，参数可改）**
- 时间步 1 h，一回合 = 24 步（一天）；
- 状态：`[小时, 电价, 负荷, SOC]`，前三项做 min-max 归一化；
- 动作：`0=放电, 1=待机, 2=充电`，充放电按功率上限 15 kW 执行，并被 SOC 边界截断；容量 60 kWh，效率 0.95，初始 SOC = 0；
- 只允许放电供本地负荷，不向电网倒送；
- 电网购电功率：充电时 = 负荷 + 充电功率；放电时 = 负荷 − 放电功率；
- 奖励（缩放 0.1）：

```
r_t = -(电价_t × 购电功率_t × Δt  +  循环损耗系数 × |储能功率_t| × Δt  +  无效动作惩罚) × 0.1
回合末再减：终端惩罚系数 × |SOC_末 − SOC_初|（kWh）× 0.1
```

**DQN 骨架（概念级伪代码）**
```python
Q = MLP(4 → 64 → 64 → 3)              # 输出 3 个动作的 Q 值
for episode in range(300):             # 每回合一天
    s = env.reset()
    while not done:
        a = random_action() if rand() < eps else argmax(Q(s))   # ε-贪心
        s2, r, done = env.step(a)
        replay.push(s, a, r, s2, done)
        batch = replay.sample(64)
        y = r + γ * max_a' Q_target(s2, a') * (1 - done)          # Bellman 目标, γ=0.95
        minimize SmoothL1(Q(s, a), y)
        s = s2
    eps = max(0.05, eps * 0.985)
    每 20 回合: Q_target ← Q
```

**输出与评价**
- 训练曲线：每回合累计奖励 + 20 回合滑动平均；
- 一天的动作序列、SOC 曲线、购电功率曲线、**累计电费曲线**（三种策略同图）；
- 指标：日购电费用（注意与奖励不完全相同，奖励里还含惩罚项）、终端 SOC 偏差、相对"无储能"的节省比例；
- 进阶上界：已知负荷和电价时用 LP 求理论最优电费，看 DQN 离最优差多少。

## 5. 教辅提示

**可布置的小实验（2 学时）**
1. 直接跑课程笔记本，记录三种策略的日电费，画累计电费曲线，让学生用一句话描述 DQN 在哪几个小时充、哪几个小时放，并对照电价表解释。
2. **改电价**：把峰价从 0.32 降到 0.16（价差变小），重新训练，观察 DQN 是否学会"干脆少动"——循环损耗项此时开始起作用。
3. **改奖励**：把终端惩罚系数设为 0，看智能体是否在最后几小时把电全放掉（或干脆不回充），讨论"奖励设计 = 告诉智能体你真正想要什么"。
4. **求上界**：用 `scipy.optimize.linprog` 把同一天写成 LP（变量为每小时充/放功率与 SOC），算理论最低电费，计算 DQN 的"最优差距"。这一步把 RL 和《电力系统经济运行》里的优化方法接上。
5. 选做（专升本 / 本科）：读文献 2 的摘要和结论，讨论"为什么在真实全年数据上，简单 MPC 可以打败深度 RL"。

**预期讨论点**：DQN 在这个确定性的单日环境里本质上是在"记住一张 24 步的最优动作表"，换一天负荷/电价就可能失效；真实部署要面对预测误差、季节变化和安全约束。玩具环境的价值在于把 MDP 概念讲透，而不是证明 RL 能直接上线。

**常见坑**
- 状态不归一化：电价 0.07–0.32 和负荷 40–70 kW 量级差很大，网络难训；
- 把"奖励"当"电费"汇报：奖励里还有循环损耗、无效动作和终端 SOC 惩罚，汇报经济性要单独算购电费用；
- 没有终端 SOC 约束：智能体会"借明天的电省今天的钱"；
- ε 衰减太快：还没探索到"先充后放"的组合就固化成只待机；初始 SOC=0 时尤其明显（必须先充电才能放电）；
- 只跑一个随机种子就下结论：至少跑 3–5 个 seed 报均值与波动；
- 忽略功率与效率约束：充 15 kW 进电池只有 14.25 kWh（效率 0.95），双向往返损耗约 10%，价差太小时套利不划算。
