# 配网短路故障分类与定位 ML 对比

日期：2026-11-12  
slug：`ml-fault-class-loc`  
关键词：继电保护，故障分类，故障定位，时序窗口，决策树，随机森林，浅层神经网络

## 今日切入

主题池下一条把「数据驱动」和「保护定值」放到同一节课里：线路发生短路后，保护装置要在几十毫秒内回答两个问题——**是什么类型的故障**（单相接地、相间、两相接地、三相），以及**故障在哪里**（哪条线、离首端多远）。前者是分类，后者是定位（区段分类或距离回归）。今天写它，是因为主题池的原始参考（arXiv:2510.00831）在 2026-06 更新了版本，给出了一个难得的「受控对比」：同一套电磁暂态数据、同样的测量和时间窗、同样的分组交叉验证，横向比较多类模型。它的结论正好适合当课堂的主线——**分类容易、定位难，而且难在拓扑，不在模型**。本篇按「两个任务的区别 → 窗口化实验草图 → 怎么诚实评价」做方法速览。

## 背景 5 分钟

**电气问题。** 传统保护靠确定性算法和固定定值：过流保护看电流幅值，距离保护用本端电压、电流算出测量阻抗，判断是否落进动作区。故障类型通常由「哪几相电流突增、有没有零序电流」判断；故障距离则来自阻抗与线路单位长度参数的比值。当配网接入大量光伏、储能等逆变器型电源后，这些前提开始松动：逆变器的故障电流幅值受限、波形与同步机不同，中间电源助增 / 汲出、平行线互感又会让单端阻抗测距产生偏差，需要按场景补偿。于是出现了一个自然的问题：直接从短窗电压电流波形里「学」出故障类型和位置，行不行，代价是什么？

**AI 方法。** 课堂上可以把它拆成两个任务，共用同一份输入：

1. **故障分类（FC）**：多分类。常见 11 类 = 无故障 + AG/BG/CG（单相接地）+ AB/BC/CA（相间）+ ABG/BCG/CAG（两相接地）+ ABC（三相）。
2. **故障定位（FL）**：可以做成区段分类（故障在哪条线 / 哪个节点附近），也可以做成回归（故障距离占线路全长的百分比）。

输入是保护安装点三相电压、电流的短窗采样（10—50 ms，在 50 Hz 下就是 0.5—2.5 个周波）。模型从线性模型（逻辑回归、岭回归）作为下限，到 KNN、决策树、随机森林、梯度提升，再到浅层 MLP。**对专科学生，最重要的直觉是：分类只需要知道「哪几相出了事、有没有接地」，信息在故障一发生的暂态里就有；定位需要知道「离多远」，而在有平行线和中间电源的网络里，不同位置可能产生非常相似的波形。**

## 方法草图

**输入（课堂尺度）**

- **仿真对象**：一条带两段线路和中间负荷的小系统即可；想贴近配网，可用 IEEE 13 节点或 34 节点馈线（OpenDSS、pandapower 均有现成模型，pandapower 只算稳态短路，暂态波形需 EMT 工具如 PSCAD / Simulink / PowerFactory EMT）。
- **故障注入**：随机抽取故障类型（10 类）、故障位置（线路全长 5%—95%）、过渡电阻、负荷水平、故障起始相角；每个组合是一个「仿真回合（episode）」。
- **窗口化**：每个回合截取故障前后各若干毫秒，用滑动窗口（如步长 5 ms，接近数字保护装置的中断周期）切出 10/20/30/40/50 ms 的窗口；包含故障前稳态的窗口标为「无故障」。
- **特征**：最简单的是直接把窗口内的原始采样拉平；对照组可用每相基波幅值 / 相角、零序分量、各相电流突变量等手工特征。
- **划分**：**按仿真回合分组**做交叉验证——同一回合的相邻窗口高度重叠，若分到训练和测试两边，准确率会虚高。

**模型或算法**

基线 — **规则法**：相电流突变量 + 零序电流阈值判断故障类型；单端阻抗法估算距离。  
模型 — 决策树、随机森林、浅层 MLP（主题池指定的三种）。  
对照 — 逻辑回归（线性下限）、KNN、梯度提升。  
统一设置 — 所有模型都先做标准化（只用训练集统计量），超参数先用默认值，比的是「任务难度」而不是「谁调参更狠」。

**输出与指标**

- **FC**：宏平均 F1（无故障窗口数量远多于故障窗口，总体准确率会掩盖小类）+ 混淆矩阵，重点看 AB 与 ABG 这类「差一个接地」的类别。
- **FL**：回归用平均绝对误差 MAE（单位：线路全长 %）；区段分类用准确率，并按线路分别统计。
- **推理时延**：单样本推理耗时，必须远小于保护动作时间窗口。
- **窗口长度曲线**：横轴 10—50 ms，纵轴 F1 / MAE，每个模型一条线——这张图是本课的核心图。

课堂用草图（概念级，不是某一仓库的训练脚本）：

```text
types = ["AG","BG","CG","AB","BC","CA","ABG","BCG","CAG","ABC"]
for ep in range(N):                                  # 每个 ep 一组随机参数
  p = sample(type=types, pos=U(5,95)%, Rf=U(0,50)Ω, load=..., inception_angle=...)
  v_abc, i_abc, t_f = emt_simulate(grid, fault=p, fs=6400)   # t_f 为故障起始时刻
  for L in [10,20,30,40,50] ms:
    for win in sliding(crop(v_abc,i_abc,t_f±80ms), len=L, step=5ms):
      X[L].append(flatten(win)); group[L].append(ep)
      y_fc[L].append(p.type if win.contains_or_after(t_f) else "none")
      if win.contains(t_f): X_fl[L].append(flatten(win)); y_fl[L].append(p.pos)

for L in windows:
  for m in [LogReg, KNN, DecisionTree, RandomForest, GradBoost, MLP]:
    cv = GroupKFold(5, groups=group[L]); scaler fitted on train folds only
    report macroF1_FC(m, L), MAE_FL(m_regressor, L), per-line MAE, infer_time
plot F1 vs L and MAE vs L; compare with rule-based classifier & impedance locator
```

## 最新公开信息

1. **受控对比（主题池原始参考）：Oelhaf、Kordowich、Kim、Pérez-Toro、Bergler、Maier、Jäger、Bayer，「Controlled Comparison of Machine Learning Models for Fault Classification and Localization in Power System Protection」，arXiv:2510.00831（2025-10 首发，2026-06 更新）。** 使用公开的 PROTECT-90 数据集：DIgSILENT PowerFactory 电磁暂态仿真、90 kV「双回线」拓扑、6400 Hz 采样、9022 个 1 s 回合，参数做域随机化，覆盖单相接地、相间、两相接地、三相短路；所有模型在 scikit-learn 默认超参数下、按回合分组的 5 折交叉验证中比较，窗口 10—50 ms、步长 5 ms。结果：FC 方面 MLP 在 10 ms 窗口宏 F1 已约 0.989，梯度提升在 30—50 ms 约 0.98 但 10 ms 跌到约 0.42，KNN 与随机森林随窗口缩短逐步变差（10 ms 时分别约 0.74、0.29），线性模型全程失败；FL 方面最好的 stacking / MLP / voting 在所有窗口下 MAE 都在线路全长约 9.7%—10.9%，第二梯队（梯度提升、KNN、决策树、极端随机树）停在约 14%—22%，**加长窗口几乎不改善**，误差随线路段不同而变化，作者认为瓶颈是平行线与中间电源造成的拓扑可辨识性，而非模型容量。推理时延：决策树约 0.04 ms、MLP 约 0.56 ms，KNN 超过 1 s，不适合实时。课堂提醒：这是 90 kV 高压双回线，不是配网；而且假设集中获取全部 8 个保护点的测量，属于性能上限。  
   https://arxiv.org/abs/2510.00831

2. **配网 + PMU + Transformer：Thakur、Parimi、Pal，「FaultXformer: A Transformer-Encoder Based Fault Classification and Location Identification model in PMU-Integrated Active Electrical Distribution System」，arXiv:2602.24254（2026-02）。** 在 IEEE 13 节点馈线上设置 20 个故障位置和多种分布式电源接入场景，只用 4 个 PMU 的电流时序，两级 Transformer 编码器先抽时序特征、再同时判类型与位置；分层 10 折交叉验证下故障类型准确率 98.76%、位置识别 98.92%，并报告优于 CNN、RNN、LSTM 基线。课堂启示：这里的「定位」是 20 个位置的分类，而文献 1 是连续距离回归——**任务定义不同，数字不能直接比**；另外分层交叉验证若不按仿真回合分组，需要回到原文确认是否存在相邻窗口泄漏。  
   https://arxiv.org/abs/2602.24254

3. **高渗透光伏与谐波下的分类：Mohamed Razick、Ahsan、Musilek，「GCN-Based Model for Fault Classification in Distribution Networks under Harmonic Distortion」，arXiv:2609.27169（2026-09，标注为 2026 IEEE PES General Meeting 论文）。** 在 OpenDSS 的 IEEE 34 节点系统上，光伏渗透率 30%/50%/70%、电流总谐波畸变 0%/1%/3%/5%，用故障前后电压电流相量（含谐波分量）映射到网络拓扑，三层图卷积网络宏 F1 约 0.98，并在最严苛工况（70% 渗透 + 5% 畸变）下优于 CNN、LSTM、MLP。课堂启示：当逆变器带来谐波时，「把拓扑结构放进模型」是文献 1 结论里提到的下一步方向之一；可作为本课的延伸讨论，不要求专科学生实现。  
   https://arxiv.org/abs/2609.27169

## 教辅提示

**小实验（由易到难）**

1. **规则先行。** 只用三相电流突变量和零序电流，写出 10 类故障的判别规则（例如「零序电流显著 → 接地类」），在仿真数据上统计准确率，找出规则最容易错的类别（通常是高过渡电阻接地）。
2. **三模型对比。** 用 20 ms 原始采样窗口训练决策树、随机森林、MLP，按回合分组 5 折交叉验证，报宏 F1 与混淆矩阵。
3. **窗口长度曲线。** 把窗口从 10 ms 改到 50 ms，画每个模型的 F1 曲线，讨论「哪种模型对短窗敏感」；再测单样本推理时间，和窗口长度放在同一张表里——提醒学生保护的总时延是「等数据 + 算结果 + 断路器动作」。
4. **定位为什么难。** 同样的输入做距离回归，画「真实位置 vs 预测位置」散点图；然后在仿真里关掉平行线或中间电源，再训练一次，看 MAE 是否明显下降，体会「拓扑造成的不可辨识」。
5. **进阶讨论。** （a）故意不分组随机划分窗口，看准确率虚高多少；（b）测试集换一个训练中没出现的过渡电阻范围或光伏渗透率；（c）读文献 3 摘要，讨论谐波畸变为什么会干扰基于基波相量的规则。

**常见坑**

- 同一回合的重叠窗口跨训练 / 测试集，结果虚高（文献 1 专门按回合分组）。
- 只报总体准确率：无故障窗口占多数（文献 1 中 10 ms 窗口里故障窗口仅约 3.2%），必须看宏 F1。
- 把只含故障后稳态的窗口拿去做定位：定位信息主要在故障起始暂态里，文献 1 只保留包含故障起始时刻的窗口。
- 不同论文的 99% 横向比较：径向馈线、双回线、区段分类与距离回归的难度完全不同。
- 忽略时延：KNN 精度尚可，但在大训练集上推理太慢；决策树极快但定位精度在第二梯队。
- 只换模型不换信息：定位误差平台期更可能需要拓扑 / 线路参数等结构信息，而不是更深的网络。

**延伸阅读。** 先读文献 1 第 II 节（数据集、窗口化、按回合分组验证），可直接照着搭实验框架；再读文献 2 的摘要与实验设置，对比「区段分类式定位」和「距离回归式定位」；对拓扑方法感兴趣的同学读文献 3。可与 11-02「LSTM 电压暂降预测」、11-10「电压质量扰动 CNN 分类」对照：同为短窗波形分类，保护场景对时延的要求严格得多。
